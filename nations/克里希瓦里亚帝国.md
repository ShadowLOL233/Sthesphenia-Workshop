# 克里希瓦里亚帝国

> NPC 大国。据 GM 2026-07-29 要点建档：首都/当代皇帝/立国叙事/反常细节/半兽人起源均已定；**唯国力面板为 GM 草拟·待校准**。秘史见文末【秘史层】。
>
> **一句话定位**：洛德法尼亚大陆**数一数二**的**以武治国**泛工业帝国——人类（主内政/经济）与半兽人（主军事/外交）**分工互补**的混居帝国。它不是"新国家"，而是米格里安帝国经**军阀内战改组**后的**当代王朝**（克里希瓦里亚＝王朝名，一如前朝米格里安）。

## 基础信息
- **国名性质**：**克里希瓦里亚＝王朝名**（非国名/地名）。**帝国本体延续**，王朝随军阀内战更替（米格里安 → 克里希瓦里亚）。
- **政体 / 统治集团**：**实有皇帝的军事帝制**；皇帝**人类或半兽人皆可**。**以武取尊**——能登帝位者非勇即将（**身经百战的勇士** 或 **统御四方的大将**）。"以武治国"传统直承米格里安。
- **当代皇帝 / 立国之君**：**梅诺罗德·涅·克里希瓦里亚**——一位**迷之起源**的人类：身形庞大、武艺超群，有"**拥有半兽人基因**"之传言，更有"其系半兽人军阀狮子王**欧布罗内·莱恩克劳姆**所领养之弃婴"的传说。无论真伪，他在**名将辈出的洛德法尼亚**亦属**出类拔萃**的存在。
- **立国 / 前朝更替**：米格里安末年**大皇帝下落不明 → 大陆级内战 → 军阀争斗改组**（约公历 1880 后，正是当年瓦夏侦得的"米格里安本土规模空前之内战"）。**克里希瓦里亚王朝的立国叙事**建立在**半兽人军阀"狮子王"欧布罗内·莱恩克劳姆遇害**（遭旧米格里安贵族陷害）所引发的帝国内战之上：其养子**梅诺罗德**以养父之名**清扫了陷害养父的旧米格里安贵族**、**重整帝国军阀政府**，确立克里希瓦里亚王朝，并走上一条**以武将为主、经民族主义与精英主义提炼**的"进化"道路——即**武人须承担起治理国家的责任**。
- **首都 / 核心领土**：**泽顿尔**（洛德法尼亚大陆东部，地图 C7）。
- **人口 / 种族结构**：**人类 ＋ 半兽人混居**为主体（二者**同为帝国主体民族**，半兽人系名副其实的自然种族——其远祖起源属秘史，见文末）。**分工互补**（承米格里安一贯传统）——**人类主内政与经济**、**半兽人主军事与外交**；帝国改革后二者差异**渐小**（但模式仍在）。
- **经济 / 技术基础**：**泛工业帝国**——工业为**绝对主导**发展路线；具备一定魔法技术但相对可忽略（未作主要路线）。可概括为"**经半兽人种族加成的人类工业帝国**"；浮晶为辅。

## 军事力量
- 主体：**半兽人为军事主干**（种族加成的强悍陆军）+ 人类工业军工；将帅治国、帝位非勇即将；承米格里安尚武 + 泛工业量产。
- 战略重心：① 与格瑞芬协同**压制黑锋**（扩张 + 生物技术泛滥）；② **警惕并预防性压制瓦夏**的军事化/工业化。
- 已知弱点：**以武治国 → 王朝更替靠军阀内战、周期性内耗**；魔法路线缺失（面对高魔文明的不对称短板）。

## 人格与行为逻辑（一致性锚点）
- 国家性格：**尚武、务实、以武定尊卑**的工业帝国；正处**改革期**——以**"武人治国"**为纲（武将为主、民族主义与精英主义提炼、武人承担治理责任），并借此**弥合人半兽分工、整合内政**。当代由立国之君**梅诺罗德**强力主导。
- **★核心矛盾/内部张力（帝国推演主轴）——梅诺罗德改革的"进化 vs 早退"**：他的"武人治国 + 民族主义/精英主义提炼"是**双刃且偏脆**的赌注，其成败即帝国当代命运的主线。三重张力：
  1. **武人治国/精英主义 ⚔ 人半兽分工的行政引擎**：泛工业帝国靠**人类文官那套内政/工业机器**才能"以武治国"而不崩；抬"武将须治国"、又已**清洗旧米格里安贵族（旧行政/权贵层）**，恐让武人挤占技术官僚 → 侵蚀工业与行政连续性。
  2. **民族主义 ⚔ "为了帝国"的后民族本质 + 来源禁忌**：帝国凝聚本是效忠抽象永续"帝国"、非民族/血统；强注民族主义逼问"我们作为一个民族是谁"，恐**触动半兽人"来源"这一敏感禁忌区**（其真相见文末秘史）。
  3. **改革过度绑定梅诺罗德个人 + 以武治国暴力继承**：改革若未在他退场前**制度化**，会随他下葬或被下一军阀翻盘；且触动既得利益、树敌极多、结构应力大。
  - **唯一翻盘变量＝梅诺罗德本人**（融合体：人身/疑半兽血/勇且似能治）：若真能熔铸出**超越种族分工的"武人-治理者"新阶层**并制度化，则为真进化奠基者。关键在——**他是在建制度，还是只在用自己一个人顶替制度。**〔结局留开，GM 推演分叉见文末秘史层〕
- 对**瓦夏（玩家）**：承米格里安态度——视其为"**自家后院冒出的入侵害兽**"（当年清扫艾格姆斯叛军时的附带牺牲品），当代则**极度警惕瓦夏联合的军事化与工业化**（潜在需再清扫的后院隐患）。
- 对**铁血格瑞芬**：正式外交往来 + **深度合作**（共同压制黑锋扩张与生物技术泛滥）——反黑锋轴心的一极。
- 对**黑锋帝国**：战略压制对象（其扩张与生物技术泛滥）。
- 红线：黑锋生物技术泛滥失控；瓦夏坐大到威胁"后院"；内部军阀失序/皇位真空。
- 行为风格：对强者（格瑞芬）＝务实结盟共御黑锋；对弱者/宿敌（瓦夏）＝轻蔑但警惕的"清扫者"姿态；对玩家＝可能**主动预防性打压**其崛起（冲突引信）。

## 反常细节（继承自米格里安）〔已定 2026-07-29〕
> 承自米格里安的一组反常（据瓦夏卫国战争情报）：战俘拒答或**高呼"为了帝国"**、对自身**"来源"含糊/反感/自相矛盾**、被研判为近乎**"佣兵城邦"**而非传统主权国、市场规则近乎游牧式野蛮。它们指向同一内核——**这不是常规"民族国家"，而是一台以武力维系、永续运转的军事-工业共同体**。
- **"为了帝国"＝对帝国本体的准宗教效忠**：忠诚不指向民族/国土/血统，而指向"帝国"这台以武力意志维系的抽象永续体——故**王朝可换、帝国不灭**，与"以武治国 + 军阀内战改朝"自洽。
- **帝国＝永续军事-工业集团**：缺乏常规"祖国/国土"认同，靠武力与工业机器维系、随征战运转；经济服务于战争机器而非定居生产（故市场逻辑显"游牧式"）。
- **半兽人对"来源"的禁忌/迷雾**（公开可观察面）：半兽人的祖源是不愿深谈、说不清之物；**其真相属世俗生物工程史包袱，见文末【秘史层】**——这层情绪也悄悄给帝国"反黑锋生物技术泛滥"的立场蒙上一重它自己都未必言明的意味。

> GM 定（2026-07-29）：本帝国**无形而上/遗迹文明式秘史**；唯一的秘史是一处**世俗生物工程**的历史包袱——半兽人的起源。

## 半兽人的真实起源（"来源含糊"之根）
- **深层起源＝被造**：半兽人（至少本帝国这一支）最初是**大灾变前某造物者的生物工程造物**（世俗的生物/炼金工程，非形而上造神；造物主身份**留白**——可选是否接某黄金时代造物势力，但**勿强行接入月之民/遗迹文明那套形而上秘史**）。
- **造物主陨落 → 自然化**：**造物主在大灾变中被吞噬**后，失去主人的半兽人幸存下来，经世代**自然演化**，**已成为如今名副其实的自然种族**——可自繁、种系独立、不再依附造物者或造物技术，与人类并肩共建帝国。**当代半兽人是真正的自然种族，不是人造物。**
- **"来源含糊/反感"＝被埋的祖源禁忌**：正因被造的祖源是一段不光彩、半遗忘、说不清的过去，半兽人（及承其传统的帝国）对"你从哪来"这类追问**天然含糊、反感、自相矛盾**（米格里安战俘的表现即此；克里希瓦里亚一并继承）。多数当代半兽人未必清楚全貌，只体验为一层挥不去的祖源迷雾。
- **反黑锋的里子＝镜像清算**：帝国与格瑞芬联手围剿黑锋"生物技术泛滥"，表面是地缘 + 道德；**里子是对自身起源的镜像不安/羞耻**——黑锋的造物技术，正是（近似）造出半兽人祖先的那类技术。此动机多半连帝国自己都不完全言明，是其反黑锋近乎偏执之烈度的深层来源。

## 〔GM 钩子·未定〕当代皇帝梅诺罗德的"迷之起源"
- 梅诺罗德（人类，却身形庞大、武艺超群、传言有半兽人基因、弃婴出身、由半兽人狮子王欧布罗内领养）的**个人来源之谜，恰与帝国"来源含糊"的反常、及半兽人被造秘史形成呼应**。
- 是否把他与那门生物工程/半兽人被造史相连（如某种回响/产物/返祖/实验遗存），**留作 GM 钩子、暂不锁定**（造物主身份亦留白）。公开层只呈现"迷之起源 + 半兽人基因传闻 + 狮子王养子传说"的浪漫化叙事。

## 〔GM 推演·结局留开〕梅诺罗德改革：奠基者 vs 流星
> 帝国核心张力（见公开层"核心矛盾"）的收束分叉，**不预先答死，由骰子与玩家行动决定**。
- **A｜进化奠基者**：梅诺罗德在反弹到来前，把"武人-治理者"新阶层**制度化**（超越人半兽分工、消化工业行政机器），民族主义提炼成功黏合而未引爆来源禁忌 → 帝国完成"进化"，他封神立朝。
- **B｜又早又潦草的流星（默认偏向）**：三重矛盾中任一先爆——技术官僚被挤空致工业/行政失能、民族主义反噬撬开半兽人来源禁忌、或触怒的既得利益（旧贵族残党/被压的文官/失意军阀）借"以武治国"的暴力继承规则发难 → 梅诺罗德**比寻常武帝更早、更潦草地退场**（暗杀/政变/新一轮军阀内战），改革随其个人一同下葬。
- **判据**：他**建制度**（A）还是**以个人顶替制度**（B）。默认结构概率偏 B，其**超常出身/能力是唯一能翻盘的变量**。
- **与来源秘史的联动**：若民族主义真的把"我们是谁"逼到台面，半兽人被造秘史（及梅诺罗德本人的迷之起源）可能被动浮出——这既是引爆点，也是通往上文 GM 钩子的门。

## GM 操作准则
- 公开层只呈现"半兽人对来源的禁忌迷雾 + 反黑锋的地缘/道德立场"；**上述被造真相不向玩家兜售**，仅用于保持 NPC（尤其反黑锋烈度、来源禁忌）行为一致性。
- **当代半兽人＝自然种族**（面板/种族权利上与人类同为帝国主体），**不因被造祖源而降格**。
