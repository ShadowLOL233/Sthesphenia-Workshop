# 克里希瓦里亚帝国

> NPC 大国。**推断·待确认稿**（据 GM 2026-07-29 要点建骨架；面板为 GM 草拟·待校准；"反常细节"节为**重点待讨论**）。
>
> **一句话定位**：洛德法尼亚大陆**数一数二**的**以武治国**泛工业帝国——人类（主内政/经济）与半兽人（主军事/外交）**分工互补**的混居帝国。它不是"新国家"，而是米格里安帝国经**军阀内战改组**后的**当代王朝**（克里希瓦里亚＝王朝名，一如前朝米格里安）。

## 基础信息
- **国名性质**：**克里希瓦里亚＝王朝名**（非国名/地名）。**帝国本体延续**，王朝随军阀内战更替（米格里安 → 克里希瓦里亚）。
- **政体 / 统治集团**：**实有皇帝的军事帝制**；皇帝**人类或半兽人皆可**。**以武取尊**——能登帝位者非勇即将（**身经百战的勇士** 或 **统御四方的大将**）。"以武治国"传统直承米格里安。
- **立国 / 前朝更替**：米格里安末年**大皇帝下落不明 → 大陆级内战 → 军阀争斗改组**，克里希瓦里亚王朝于内战中胜出、重整帝国（约公历 1880 后，与瓦夏卫国战争同期/稍后；那场内战正是当年瓦夏侦得的"米格里安本土规模空前之内战"）。
- **首都 / 核心领土**：〔待定〕洛德法尼亚大陆东部（地图 C7）。
- **人口 / 种族结构**：**人类 ＋ 半兽人混居**为主体，**分工互补**（承米格里安一贯传统）——**人类主内政与经济**、**半兽人主军事与外交**；帝国改革后二者差异**渐小**（但模式仍在）。
- **经济 / 技术基础**：**泛工业帝国**——工业为**绝对主导**发展路线；具备一定魔法技术但相对可忽略（未作主要路线）。可概括为"**经半兽人种族加成的人类工业帝国**"；浮晶为辅。

## 修正提示（裁定用，不改面板基数）
- 〔技术〕**泛工业帝国**：工业量产/军工/动员 **＋**；魔法相关行动 **−**（刻意未发展路线）。
- 〔种族〕**半兽人种族加成**：军事/体力/边疆战/近战 **＋＋**。
- 〔情境常备〕**以武治国 + 王朝靠军阀内战更替**：强人政治稳定但**皇位以武力争夺**，权力更替周期剧烈、代价大（结构性内耗风险）。
- 〔地缘〕**与铁血格瑞芬深度合作**（压制黑锋扩张 + 黑锋生物技术泛滥）：涉黑锋的行动 **＋**（有协同/盟援）。
- 〔地缘·历史〕**对瓦夏＝承米格里安"后院害兽"轻蔑 + 对其军事化/工业化极度警惕**：涉瓦夏的戒备/预防性打压倾向 **＋**（视其崛起为需清扫的后院隐患）。

## 军事力量
- 主体：**半兽人为军事主干**（种族加成的强悍陆军）+ 人类工业军工；将帅治国、帝位非勇即将；承米格里安尚武 + 泛工业量产。
- 战略重心：① 与格瑞芬协同**压制黑锋**（扩张 + 生物技术泛滥）；② **警惕并预防性压制瓦夏**的军事化/工业化。
- 已知弱点：**以武治国 → 王朝更替靠军阀内战、周期性内耗**；魔法路线缺失（面对高魔文明的不对称短板）。

## 人格与行为逻辑（一致性锚点）
- 国家性格：**尚武、务实、以武定尊卑**的工业帝国；正处**改革期**（弥合人半兽分工、整合内政）。
- 对**瓦夏（玩家）**：承米格里安态度——视其为"**自家后院冒出的入侵害兽**"（当年清扫艾格姆斯叛军时的附带牺牲品），当代则**极度警惕瓦夏联合的军事化与工业化**（潜在需再清扫的后院隐患）。
- 对**铁血格瑞芬**：正式外交往来 + **深度合作**（共同压制黑锋扩张与生物技术泛滥）——反黑锋轴心的一极。
- 对**黑锋帝国**：战略压制对象（其扩张与生物技术泛滥）。
- 红线：黑锋生物技术泛滥失控；瓦夏坐大到威胁"后院"；内部军阀失序/皇位真空。
- 行为风格：对强者（格瑞芬）＝务实结盟共御黑锋；对弱者/宿敌（瓦夏）＝轻蔑但警惕的"清扫者"姿态；对玩家＝可能**主动预防性打压**其崛起（冲突引信）。

## 反常细节（继承自米格里安）〔**重点·待 GM 讨论**〕
> GM 定：**无形而上/遗迹文明式秘史**，但**米格里安的"反常细节"被克里希瓦里亚继承**——具体内涵＝**本次重点待讨论**。米格里安旧反常（据瓦夏卫国战争情报）：战俘拒答或**高呼"为了帝国"**、对自身**"来源"含糊/反感/自相矛盾**、被研判为**近乎"佣兵城邦"**而非传统主权国、市场规则**近乎游牧式野蛮**。
> **候选读法（我的推断·待你拍板，可选/可合并/可否决）**：
> - **A｜"为了帝国"＝对帝国本体的准宗教效忠**：忠诚不指向民族/国土/血统，而指向"帝国"这台以武力意志维系的抽象永续体（故王朝可换、帝国永续，与以武治国自洽）。
> - **B｜"来源含糊"＝半兽人来源的禁忌**：半兽人起源是说不清、不愿说之物。子选：(i) 半兽人系某种（早期/世俗的）人为培育/生物工程产物——**讽刺地**，帝国如今与格瑞芬联手压制黑锋生物技术泛滥，恰因对"人为造种"有切肤之不安（自身来源的镜像）；(ii) 半兽人系大灾变遗留的无祖地混种群，故"来源"无从答起。（均为**世俗**史包袱，不涉形而上，符合"无秘史"。）
> - **C｜"佣兵城邦/游牧式"＝帝国本质是一支永续的军事-工业集团**：无传统"祖国/国土"认同，而是靠武力维系、随征战与工业机器运转的战争共同体；故"来源"于其成员无意义，经济服务于战争机器而非定居生产。
> — 详见会话讨论；定案后回填本节并去除〔待讨论〕标记。

## 在玩家叙事中的作用
- **瓦夏（玩家）的历史宿敌承继者 + 当代最大外部戒备源**；洛德法尼亚地缘主轴之一。
- 可被玩家利用/激怒/拉拢的钩子：**格瑞芬—克里希瓦里亚反黑锋轴心**（第三方可撬动）；**人—半兽分工**的内部改革张力；**以武治国的军阀更替**（皇位真空＝干预窗口）；**对瓦夏崛起的预防性打压**（可能主动挑起冲突）。
