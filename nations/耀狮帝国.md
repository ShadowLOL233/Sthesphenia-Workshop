# 耀狮帝国

> **欧西尼亚大陆西南部最大的人类工业强权**，首都**贝尔法瓦尔**。砖红巨块压住整个西南，是本区的地域强权。**立国之魂＝人类至上主义**——一套源于弱者存在恐惧、却对亚人施行单方面剿灭/压榨/奴役的意识形态。

## 基础信息
- 政体 / 统治集团：**再光复英雄后裔的军事贵族制**（人类工业帝国）；立国意识形态＝**人类至上主义**。
- 首都 / 核心领土：**贝尔法瓦尔**；欧西尼亚西南（r2_c0），东接艾尔希迪斯帝国、北邻费尔伦德尔帝国。
- 历史定位：**西南第一人类工业强权 + 人类至上主义帝国**——乱世中建立的人类主导工业帝国。
- 主要种族：**人类为核心**；**精灵（高等种）/ 矮人（兄弟种）以"恩典"被接纳入"文明共同体"**；**亚人（除精灵矮人外的类人种）＝被剿灭/奴役的底层**。

## 人类至上主义（GM 2026-08-30 给料 · 立国意识形态）
> **根源是悲剧性的恐惧，但其实践＝对亚人的单方面剿灭/压榨/奴役**——根源解释"为何"，**不减轻"做了什么"**。

### 根源：被逼出来的弱者意识形态
- 大灾变后多族多文化的混乱中"**被迫**"催生。**人类在建起自己的魔法体系或工业技术之前，冷兵器时代几乎一直是弱势的一方**。
- 人类唯一的结构性优势＝**更擅长组建大规模文明/社会 + 足够强的凝聚力**；但这类人类帝国只是**历史个例**，名义人类统治下常压不住四处的**亚人叛乱**，地图默认底色反而是**碎片化的亚人种族国/氏族**。
- 故人类至上主义**不是强者的傲慢，而是弱者的存在恐惧**——一种"不凌驾便被淹没"的补偿/防御性意识形态。

### 边界：以人类为中心的"广义文明共同体"
- **主语永远是人类**。**精灵＝人类的高等种**（凭**样貌、寿命、智慧**，非魔法天赋；是"突破凡俗的可达卓越"，**非人类膜拜/信仰的对象**）；**矮人＝人类的兄弟种**。
- 人类**以"恩典"接纳**精灵与矮人，三族**互帮互助**，建一个**不被下等野蛮亚人染指的社会**。要害＝**"谁算我们"的裁定权始终握在人类手里**：可以欣赏精灵之卓越，却绝不臣服（**品质高 ≠ 主权**）。
- 对**自主的高等精灵强权（如[法涅罗斯](法涅罗斯帝国.md)）**：这份"我恩准你加入"的姿态在骄傲的精灵看来近乎冒犯 → 耀狮多是**"伸出恩典却不被领情"的拧巴**；境内被接纳的精灵/矮人则偏**同化者/合作者**。

### 对亚人：或剿或奴，且从未想过共存
- **亚人＝除精灵、矮人外的类人种族**（半兽人/蜥蜴人/四足人/羽翼人/鱼人/巨人等）。
- 病灶不是"权衡后选择压迫"，而是**从未想象过人亚共存**——世界模型里只有"淹没或被淹没"、没有第三格。故对亚人**单方面剿灭 + 压榨 + 奴役**：亚人只有两种身份——**威胁（剿）或资源（奴）**，从来不算"人"。
- 以**"文明 vs 下等野蛮"**自我正当化（亚人会"染指/玷污"文明）——给种族清洗镶了道德金边，比裸的生物种族主义更有说服力、也更阴险。

### 工业＝让人类至上"第一次可行"的均衡器
- 弱而众的人类，靠**工业量产**去压过强而寡的异族——**工业不是耀狮碰巧点的科技，而是让人类至上头一回跑得通的那件武器**。这解释了耀狮"**既工业、又至上**"的因果，也解释了它为何是"成功运转版"（而光排外、无均衡器的[巴扬坦王国](巴扬坦王国.md)会崩）。
- 魔法是**另一条均衡器**（[费尔伦德尔](费尔伦德尔帝国.md)走的路）；耀狮**轻视魔法**、笃信工业独尊 → **吉亚尔马吉亚战争**中被费尔伦德尔的魔武双轨反制、由上风转落下风（详见 `费尔伦德尔帝国.md`）。

### 阶级泄压阀：社会稳定的承重墙（也是裂缝）
- 工业资本主义**照样压榨人类工人**，但人类工人**脚下永远垫着亚人**。**种族等级＝阶级矛盾的泄压阀**：人类工人的怨气被**向下导向亚人**、而非向上指向资本；"你再惨也是主人种族"的**心理工资**把人类工人与人类资本**捆在一起**。
- 故**社会整合（社6）是"有条件的稳定"**。三组耦合炸药：①**亚人奴工暴动**（工业底层正是它最恐惧的亚人）；②**人类劳工运动**（平时被种族团结压住、经济危机时冒头）；③**最致命——跨种族的阶级联合**（阶级团结溶解种族秩序）。
- 由此耀狮**天然与阶级团结型意识形态为敌**（如社会主义的**艾尔托尼亚联盟**）——一条潜在意识形态对立轴。

### 对费尔伦德尔：不止敌意，是"审美-道德的恶心"
- 费尔伦德尔把**亚人熔进"人族"血脉**，在耀狮眼里＝**让野蛮染指了文明、把高贵掺进粗料** → 一种**亵渎/生理性恶心**，比单纯地缘敌意更深（也加剧了吉亚尔马吉亚战争的不可调和）。

## 立国史（GM 2026-08-30 给料）
> 耀狮的立国史＝**人类在该地区的血泪史**，也是其人类至上主义与"大一统"信仰的根。

- **源头：精灵古帝国瑟伦贝浮尼亚**（[旧帝国期·公历1200前](../setting/geography.md)）——**精灵主导的多种族帝国**，几乎控制整个 r2_c0（除费尔伦德尔/艾尔希迪斯外）。**但其衣钵从精灵落入人类**：瓦解后经**数代人类继承皇朝的更迭**（非直系）。
- **耀狮的直系前身＝一个短命的人类"旧帝国"**：只占据**今耀狮实控疆域**、相对短命；**它的解体，直接掀翻了这片地区、放出了亚人军阀主导的混乱**。
- **深渊：亚人军阀混乱**（类华夏唐末五代十六国）——人类沦为弱势、几乎立不起安全的口袋，饥荒下人相食，且**亚人捕猎人类为食**，血流成河、白骨堆山。**"人类国家一散架就沦为牲口"由此被血写进集体记忆**——正是"大一统"神圣不可犯的根。
- **再光复战争（约公历1200 收束·历时近百年）**：一群**雇佣兵 + 一个本地领主**组成的人类联军**掀起人类至上主义大旗**，**第一次真正压制了亚人、把该地区引入人类主导的时代**。
- **耀狮帝国立**：以再光复之功重建**大一统人类工业帝国**，统治阶层＝**再光复战争英雄后裔的军事贵族**。
- **立国神话＝"谁配继承人类文明的荣光"**（此处"人类"＝人类至上主义下的**广义人类＝人类+精灵+矮人**）。关键的意识形态操作：既然**精灵＝人类的高等种**，精灵所建的瑟伦贝浮尼亚便被**追认为"人类文明"的成就**——耀狮的人类至上思想借此**"占"了这个精灵帝国的光**（以类别扩张把精灵功业并入"广义人类"、**抹去其精灵独立性**）。故耀狮不是"接精灵的班"，而是"**人类文明夺回自己的遗产**"。
- 〔法统对照 · 待 GM 采纳的钩子〕同争这份"人类文明荣光"者还有 **瑟里昂提亚/安纳格拉斯（人类+半兽人）**——但在耀狮眼里，它们**把亚人粗料掺进了人类文明、就此失格**，根本不配继承。〔此为耀狮主观视角，暂只记于本档〕
