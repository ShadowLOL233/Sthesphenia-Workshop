# 费尔伦德尔帝国

> **审批级别 C4（原 map-only 大国）**。GM 2026-08-30 给料：首都**扎塔特拉克**；**极少数同时走魔法技术与工业技术的国家**，且是一个**试图建立跨种族共同文化认同与社会架构的国家与文明**。面板（0–10）已草拟·待校准（见下）；技术等级 **T3**。

## 基础信息
- 政体 / 统治集团：**君主制 + 议会制**——皇帝及其核心决策圈为顶、**统合议会**为其下（必要时代行决策圈）；**政治层已完全由混血种精英构成**，皇室本身即熔合政策的先驱（详见"政体与统治"）。
- 首都：**扎塔特拉克**（GM 2026-08-30）。
- 地理定位：欧西尼亚西南偏北（**耀狮帝国之北**，r1_c0 东南 / r1_c1 西南，橙色）；西海一带。
- 技术路线：**魔法技术 × 工业技术双轨并行**——全瑟斯芬尼亚**极少数**同时深耕两条技术路线者。
- 主要种族：**"人族"**——人类/精灵/矮人/半兽人经通婚熔合、统称一族并以此自居（详见下"跨种族熔合文明"）；混血种已现，惟仍大量保留父母一方体态特征。

## 跨种族熔合文明（GM 2026-08-30 给料 · 核心特征）
- **起源＝借鉴[百国公约](百国公约.md)经验的本土化产物**：得益于百国公约在多族共处上的卓越成就，费尔伦德尔**取百国泛种族主义之经验、本土化**为己用——但走得更远：不止共处，而是**主动推动人类/精灵/矮人/半兽人通婚、血脉混合**。
- **成果＝成功构建"人族"新社会（历史已认可）**：帝国**成功建成一个容纳人/精/矮/兽的新社会**。其观念下**不再区分人类/精灵/矮人/半兽人，四族统称"人族"、以人族自居**——**类似"同一文化下的多个少数民族"**：一个文化认同之下的多支族群。
- **生物层面尚未成"新种族"**：**混血种已出现**，但**种族血脉隔阂仍过深**——混血个体**仍大量保留父母一方的生物体态特征**（依基因选择显性）。故当前是**社会/文化层面的熔合成功**，**生物意义上的"新种族"尚未成形**。
- **社会摩擦＝相对成功、由皇权派强力弹压**：内部长期存在**纯血派 ↔ 混血派**之争，但帝国**凭精明政治操作 + 对国家暴力机器的掌控**，**极大压制了两派对皇权派的威胁**（皇权派＝居中掌控的统治派系）。
- **通婚制度＝已从"鼓励"推进到国家政策"半强制"**：透过**生育补贴 + 社会福利**维持**高混血人口出生率**——一套强力的国家社会工程。
- **历史学家的结构类比＝对"龙律"社会的"粗劣复刻"**：龙律治下以**龙族为骨干、龙裔为肌肉、盟族为血管**；费尔伦德尔的熔合被视为对此结构的**粗劣仿造**——**远达不到龙族帝国（[艾尔希迪斯](艾尔希迪斯帝国.md)）的高度**，却因此**造就其独一无二的文化**。
- **遗迹文明视角下"极其激进"**：与其说极端激进，不如说**费尔伦德尔在这方面的努力与投入，在整个瑟斯芬尼亚也是独一档的**。

## 政体与统治（GM 2026-08-30 给料）
- **君主制 + 议会制**：皇帝及其**核心决策圈**为顶；**统合议会**居其下，是**仅次于皇帝核心决策圈、必要时可代行其职权**的权力机构。
- **政治层＝清一色混血种精英**，**皇室即"统合血统"政策的先驱**（皇室带头混血）。
- **统合议会的由来＝一场早期继承危机**：政策推行初期**混血生育问题极多**，一度使**皇室产不出合适的继承人**——为保治理延续，遂催生**统合议会**这一后备/代行机构。〔推演钩子：混血生育不稳＝皇室潜在继承脆弱性，统合议会为其制度缓冲〕
- **纯血派＝被边缘化的地方各族精英**：地方仍有**不接受"统合血统"思想的各族精英**，但已**日益边缘化、被挤出帝国权力中心**。
- **首都扎塔特拉克＝政治中枢 + "统合血统"思想核心试验地**：城中并存**四族文化风格的建筑**与**统合思想催生的新一代建筑**；相貌各异而**思想/血统统一**的"人族"共用**同一语言、同一货币、同一文化**——"仿佛泛种族主义的天堂"。

## 与艾尔希迪斯（龙族·龙律）的关系（GM 2026-08-30 给料）
- **一段"互不意识"的非关系**：费尔伦德尔对龙族而言**不是特例、而是常例**——双方仿佛都未"意识"到对方的分量。
- **龙族视角＝漠然**：费尔伦德尔只是**又一个新生帝国**（以龙族尺度，其及前身"不过"存在了**至少百年**）；**既未触犯龙律、也不染指遗迹技术**——故龙族**不关心其改革与行为是否在模仿自身法则**，只履行**守望者文明的职责**（合正典 passive 守望：不越界则不动）。
- **费尔伦德尔视角＝远望的敬畏**：视艾尔希迪斯如**深邃的夜空**——虽无璀璨星光，却能从点缀其间的些许亮光，窥见**龙族帝国的深邃与强大**。
- **"别扭的邻居"格局**：因艾尔希迪斯是个**无法在外交意义上接触**的国家，费尔伦德尔只能以别扭的方式与之为邻——**官方不建立任何关系，但允许民间商贸与部分文化往来**。

## 已确立的定位（自邻国正典侧写）
- **欧西尼亚西南两大人类工业强权之一**（与[耀狮帝国](耀狮帝国.md)并列的另一极）。
- **与耀狮共建[吉亚尔马吉亚王国](吉亚尔马吉亚王国.md)** 作缓冲傀儡，隔开两强。
- **"耀狮-费尔伦德尔战争"（＝吉亚尔马吉亚战争）** 的一方——其战后乱局＝[沃里德基尔希亚公国](沃里德基尔希亚公国.md)独立的契机（详见下"耀狮-费尔伦德尔战争"节）。
- **老牌强权**：旧帝国期（公历1200前）的**精灵古帝国**[瑟伦贝浮尼亚](../setting/geography.md)几乎控制整个 r2_c0，**独"费尔伦德尔与艾尔希迪斯"疆域除外**——暗示费尔伦德尔自古即已自立、与龙族艾尔希迪斯同为区域老牌力量。

## 耀狮-费尔伦德尔战争（＝吉亚尔马吉亚战争 · GM 2026-08-30 给料）
> 又名**吉亚尔马吉亚战争**（以战场所在地区"吉亚尔马吉亚"命名；战后即在该地区建吉亚尔马吉亚王国为缓冲）。

- **性质与时间（GM 2026-08-30 定）＝惨烈但有限的区域大国战争，发生于开局（1890）前数十年**：有边界的战区、以谈判 + 建缓冲国收场，**非举国灭国级总体战**，故**不留一代人级的人口断层**；到 1890 **经济与军力均已基本恢复**（面板即取此恢复后的常态，战损不压基数）。
- **起因＝意识形态对撞**：[耀狮帝国](耀狮帝国.md)是**乱世中建立的人类主导帝国**，人类至上主义近乎其"自带标签"；一个人类至上帝国**无法容忍一个本质上非人类至上、且体量国力都与自身匹敌的邻国存在**——尤其**费尔伦德尔的地理位置**使耀狮无法无视这一意识形态威胁。**费尔伦德尔并不主动讨伐人类至上主义，而是以自身的存在与繁荣作为最有说服力的"话语权"**（活的反例，非十字军）。
- **转折＝耀狮栽在对魔法的傲慢上**：耀狮凭**新兴工业力量**开局取得上风；但战前**根本没把魔法技术放在眼里**——自信在工业炮火与钢铁面前，旧时代法术即便能有效威胁工业产物、**也无法在数量上与之抗衡**。耀狮却忽视了两点：**①错估了工业技术本身对战争形式的改变；②忽视了在工业主导的战争中、魔法军事技术仍有一席之地**。费尔伦德尔的**魔武双轨**由此发力 → 战线焦灼 → 耀狮攻势后继乏力、**逐渐落于下风**。
- **结果＝耀狮求和、费尔伦德尔顺势收筹码**：耀狮提议和谈；费尔伦德尔虽也**损伤惨重**，但这场"恰到好处"的战争**恰好为其"统合血统"政策的推行打了一针鸡血**（外部威胁→内部凝聚）——故**巴不得停战**，遂以**战场筹码进一步要求建立缓冲区** → 依和约在**吉亚尔马吉亚地区**建[吉亚尔马吉亚王国](吉亚尔马吉亚王国.md)为两强缓冲。
- **余波**：战后乱局 → [沃里德基尔希亚公国](沃里德基尔希亚公国.md)借机独立；耀狮此后屡次战后收复皆被挫败。
- **主题**：**纯工业新锐（耀狮）因轻视魔法 + 错估工业化战争 → 败给魔武双轨的老牌（费尔伦德尔）**——一场印证"双轨"价值的战争。

## 军事（GM 2026-08-30 给料）
- **传统建军＝魔法为主、工业为辅**：战术战略与军事技术长期以**魔法军事技术为主干、工业为辅**。
- **吉亚尔马吉亚战争中被迫转向"工业为主、魔法为辅"**：因**在魔法技术取得突破之前，只有工业技术能在短时间内让大规模部队形成基本战斗力**（魔武难以快速规模化成军）——战争压力下临阵把军事重心倒向工业。这也解释了它为何能与纯工业的耀狮鏖战到底、并最终迫其求和。

## 修正提示（裁定用，不改面板基数）
- 〔技术〕**魔法×工业双轨**：魔武结合/法阵-火器 ＋；但**魔法军事难快速规模化成军**（突破前量产战斗力靠工业）——闪电动员偏工业。

- 〔情境〕**统合议会**：皇室继承脆弱时的治理缓冲（继承危机不致断政）。
