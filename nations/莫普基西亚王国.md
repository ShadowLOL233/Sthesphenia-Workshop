# 莫普基西亚王国

> 中档 NPC 档案。首都**诺登**。**精灵为名义主体（人口稀少）、人类／鱼人／羽翼人为人口基座（demographic 主体民族）** 的多族王国。地处**连接欧西尼亚南部华夏文化圈与东南部地区的主要陆上交通走廊**上，是**该地区首要的经济、政治与军事力量**。其巨富几乎由**瀚末乱世**一手造就——瀚朝瓦解、东齐尚未立、军阀混战之际，王国**收买前瀚朝人员、并向瀚朝进出口商业链安插自己人**，几近独家包办了原本由瀚朝朝廷操办的进出口贸易。曾是一个**早已灭亡的无名旧帝国**的一部分（该帝国故地含莫普基西亚、多尔基亚、霍夫登内西亚、布罗兰德里亚、罗萨米亚，及**角鲸联邦西部**部分领土）。

## 基础信息
- 政体 / 统治集团：**王国**；精灵贵族为名义统治主体（人口稀少），人类／鱼人／羽翼人构成人口与经济基座。
- 首都 / 核心领土：**诺登**；欧西尼亚东南半岛，扼华夏文化圈↔东南欧西尼亚的陆上贸易走廊。
- 人口 / 经济基础：多族；经济命脉＝**垄断性的瀚故地进出口贸易**（瀚末乱世中夺取）。
- 立国神话 / 历史定位：**无名旧帝国核心继承者**（旧帝国故地含本组五国 + 角鲸联邦西部）；当代崛起靠瀚末贸易霸权。

## 修正提示（裁定用，不改面板基数）
- 〔特征·成对〕**瀚末贸易霸权**：垄断前瀚朝进出口 → 经济/对外结构性峰；但**命脉系于瀚故地贸易**——若东齐/朔朝重建朝贡贸易秩序、或对其封锁，经济受冲击（详见 `relations/oseania.md`）。
- 〔地缘〕**陆上交通走廊枢纽**（华夏文化圈↔东南欧西尼亚）：贸易/对外 ＋；但也是商路/兵家必争、多方渗透之地。
- 〔种族〕精灵统治（人口稀少）+ 人类/鱼人/羽翼人基座：魔导/外交 ＋、水域/空域兵种特色；**统治层稀薄** → 合法性/代表性张力（社会整合 −）。
- 〔历史·成对〕**无名旧帝国核心继承者**：法统/故地叙事 ＋，对多尔基亚/霍夫登内西亚/布罗兰德里亚/罗萨米亚及角鲸联邦西部可主张同源/宗主（进 `relations`）。
