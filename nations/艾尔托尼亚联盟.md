# 艾尔托尼亚人民社会主义共和国联盟（艾尔托尼亚联盟）

> 已据 GM 口述要点更新为"当前形态（公历 1890）"。前身**自由普罗斯纳共和国**（三大家族寡头制）经**社会主义革命**及席卷全大陆的内战，转变为**艾尔托尼亚联盟**——一个**苏维埃 + 朝鲜式先军政治**的孤立主义大国。旧 docx 的工业/派系细节是底盘（三大家族已覆灭）。

## 基础信息
- 政体 / 统治集团：**苏维埃形式 + 先军政治（类朝鲜）的结合体**。奉行**孤立主义**——"具备苏联国力（体量）的类朝鲜缝合体"。
- 定位：横跨**数百万平方公里**的大国，**地大物博**；但革命初生 + 数十年大规模征战使其**极度虚弱**——政治理念→实际政策的转化艰难，能否用好地大物博的优势、巩固革命果实尚是未知。
- 命名：**取自所在大陆"艾尔托尼亚"**。
- 首都 / 核心领土：普罗西斯克城（革命策源地普罗斯纳）；奥尔顿登西山脉分南北。
- 经济基础：继承并吸收了**前三大家族的基建与人才**；重工业+矿业底盘仍在，但被战争严重消耗、且因孤立难获外部交流。
- 立国/革命理念：**艾尔托尼亚版社会主义**。**关键限定——这场社会主义革命仅限"人类"范畴，非人类物种未被包括在内**（北方半兽人等被排除，埋下族群张力）。
- 主要种族：**人类**（革命主体，近乎单一）；北方半兽人等**已在革命中被驱逐或清洗**（"仅限人类"的社会主义落为族群清洗/驱逐）——被逐者流散境外，成为外部变量。

## 修正提示（裁定用，不改面板基数）
- 〔政策/地缘〕**孤立主义（类朝鲜）**：对外贸易/外交/外援 −−（自我封闭）。
- 〔情境常备〕**革命后极度虚弱**：大规模建设/改革处于**恢复期** −（理念→政策转化艰难 + 数十年征战消耗）。
- 〔资源〕**地大物博（数百万 km²）**：潜在动员/资源 +（但"能否用好"存疑，是叙事悬念）。
- 〔技术/政策〕**先军政治**：军事优先，民用/非军事发展 −。
- 〔情境常备〕**社会主义仅限人类、排除非人类**：半兽人等非人类相关事务 = 离心/张力隐患。

## 军事力量
- 继承普罗斯纳工业化火器体系（火枪—火炮全军量产），经革命大陆内战锤炼；**先军政治**下军队为国家核心。
- 已知弱点：新政权虚弱、恢复期；孤立难获外部军技；非人类被排除的内部张力。

## 人格与行为逻辑（一致性锚点）
- 国家性格：孤立、警惕、先军；以巩固革命果实为压倒一切；对外封闭、对内高度动员。
- 核心矛盾（1890）：巩固革命 vs 极度虚弱（理念落地难 + 战争创伤）；人类社会主义 vs 被排除的非人类；地大物博 vs 无力充分开发。
- 战略目标：休养生息、巩固革命果实、消化吸收前三大家族基建、维持孤立自保。
- 红线：外部干涉/反革命复辟（尤其新生的反动帝国）；三大家族残余/流亡势力反扑；被排除族群的暴动。
- 对待各方：对外孤立自守、警惕反革命；对内先军高压动员。

## 沿革与开局态势（公历 1890）

### 社会主义革命与大陆剧变
- **主导者**：**军中革命派** + 少部分从人民革命党分离出的**理想派**（奉行艾尔托尼亚版社会主义，**仅限人类**）。
- **三大家族结局**：革命中**土崩瓦解**，部分逃亡联盟外地区；**前普罗斯纳境内已无三大家族势力**，其基建与人才被联盟吸收。
- **范围（大陆级）**：革命不仅在普罗斯纳境内爆发**残酷内战**，更**席卷周边**——促使 **埃尔瓦尼亚王国、帕纳提斯专制体、东支提斯王国、卡里南大公国、正统阿尔戈斯联合、肖普巴赫联合体** 的**解体与灭亡**；同时促使 **隆德拉特帝国** 与 **阿多斯提洛索亚帝国** 的**建立**（两个新帝国——很可能是反革命/反动的对抗方，待建档）。
- **结果**：诞生横跨数百万 km² 的艾尔托尼亚联盟，但**极度虚弱**——"取得革命果实的联盟能否运用好地大物博的优势、巩固果实"，是其开局的核心悬念。

## 已确认（2026-06-25）
- **主要外敌 = 帝国联盟阵线**：革命催生的 **隆德拉特帝国 + 阿多斯提洛索亚帝国** 结成**帝国联盟阵线**，将是**开局后艾尔托尼亚大陆的重要剧情引线**（联盟的头号外部对抗方）。二帝国已各建 NPC 档案。
- **与瓦夏联盟**：**不同意识形态阵营、道路分开、无正式往来**。
- **北方半兽人**：革命中**已被驱逐或清洗**（"仅限人类"的社会主义在此落为族群清洗/驱逐）。
- **南奥尔顿登西独立运动**：**已被并入**席卷全大陆的社会主义革命（不再是独立诉求，而是革命的一部分）。
