# 第二奥古斯特帝国

> **前身古特尼亚大公国**（前提顿帝国的一部分），首都即被占据的旧帝都**凯撒多尼亚**。古特尼亚家族是**提顿帝国崩溃性解体后最成功的帝国家族**——赢家不是武力最强的莫克瑟克亲王国，而是提顿诸势力中**最中庸却最稳健**的古特尼亚。凭当代家主的战略方针，以**军事＋政治手段**称霸一方，终占凯撒多尼亚、自立第二奥古斯特帝国。（维托里斯视其为**外族僭主**——它本是提顿血脉、却窃据奥古斯特帝位。）

## 基础信息
- 政体 / 统治集团：帝国（古特尼亚家族——原提顿帝国的中庸稳健派，今自立奥古斯特皇统）。
- 首都 / 核心领土：**凯撒多尼亚**（旧奥古斯特帝都，攻占后为都）；欧西尼亚南 r2_c2 左。
- 历史定位 / 崛起：**提顿帝国**（以武人立国/治国、武力至上→注定短命；首任皇帝离奇猝死后陷军阀混战）解体，古特尼亚以稳健胜出——**攻占凯撒多尼亚前**：① 吞并提顿西部边境的**两个军镇公国**；② 以**外交离间**迫使**莫克瑟克亲王国、胡安查尼亚亲王国、维芬比亚大公国**三方混战，为自己争得介入**第一奥古斯特帝国解体**的时间与空间。
- 主要种族：〔推断〕人类为主（提顿武人帝国谱系），待 GM。

## 修正提示
- 〔特征〕**中庸稳健 + 外交离间**：定难度时联盟/离间/政治博弈类行动 ＋；一味蛮力反非其长。
- 〔情境〕**外族僭主·合法性存疑**：占奥古斯特帝位却非其文化血脉——被征服区整合 −、对奥古斯特文化圈号召力受限（维托里斯据此争正统）。
- 〔地缘·成对〕对**洛伦尼亚统治领**屡屡进犯、**均被击退**；与**维托里斯共和国**争奥古斯特正统（详见 `relations/oseania.md`）。
