# 舒希安议会

> 迷你 NPC 档案。首都**安多赛特**，一个**由鱼人和半鱼人主导的海岛贸易议会制国家**。值得一提的是——舒希安议会所在的群岛是**有名的海盗聚集地**，而**这些海盗正是议会能调遣的主要军事力量**：他们训练有素、装备精良，甚至拥有**足以匹敌正规国家海军的舰船**。

## 基础信息
- 政体 / 统治集团：议会制（鱼人/半鱼人主导的海岛贸易议会）。
- 首都 / 核心领土：**安多赛特**；欧西尼亚南 r2_c2 东部海岛（金玉海屿一带的著名海盗群岛）。
- 历史定位：**海岛贸易议会 + 海盗军力共生体**——议会以贸易立身，以群岛海盗为爪牙；海盗训练有素、装备精良，海上武力不逊正规海军。
- 主要种族：**鱼人 + 半鱼人主导**（水战/航海见长）。
