# 黑锋帝国

> NPC 大国（**GM 接管·洛德法尼亚重要 NPC**）。
> **一句话定位**：洛德法尼亚（弗里亚塔尤因）中央的**非世袭君主专制**帝国，以**奇诡生物科技（黑水/深渊骑士）与精良锻造**闻名；恶劣环境铸就高利他主义的**阿佐兰尼**文化与**选贤尚武**继承制。最大内部隐患＝正在"**制造神明**"、日益壮大的**断罪教**。当代被**克里希瓦里亚 + 铁血格瑞芬"反黑锋轴心"**联手压制（针对其扩张与生物技术泛滥）。

## 基础信息
- 政体 / 统治集团：非世袭君主专制；皇位选举制（笔试+体力+对改造生物掌控度），皇子需经平民抚养与"黑谷七日"考验才有继承权，外人理论可参选（260年来无外人当选）；承相主管农/军/技三司，监查司反腐、通报司通报民意。
- 首都 / 核心领土：黑锋峰一带（最高学府席兹大学院所在）；南方为最大农业产地与商业港口（断罪教主基地）。
- 人口 / 经济基础：以阿佐兰尼人及其改造体为主；第一产业（农业）发达、轻工业薄弱但自给；政府定期屯粮与购精神药物防"小意外"；主要出口金属矿石及工艺品、寒带作物/草药/香料、寒带生物肉品；按生产要素分配（多劳多得）。
- 立国神话 / 历史定位：旧帝国科考队覆灭后，哈桑部落回收矿井残存科技起家，约1580年强盛、1660年统一部落建黑锋帝国；1730年雷坎尔将军与五代女皇通过解析深渊之井旧帝国科技带来生物科技革命，1795年七代皇帝登基。
- 主要种族：潘斯派特（人类原住民）、潘斯派多森（杂种人/改造人）、文多森（公民权怪物）、多文（非公民权怪物）。

## 修正提示（裁定用，不改面板基数）
- 〔技术·生物〕**黑水 / 深渊骑士 / 生物炼金**：涉生物兵器、寄生、改造生物、生存环境战 **＋＋**；但**生物技术泛滥**招致邻强（克里 + 格瑞芬）联手压制（成对项见 relations）。
- 〔技术〕**精良锻造 / 金属工艺**：锻造、冷兵器、金属制品 **＋**；轻/常规工业 **−**。
- 〔情境常备〕**选贤尚武 + 黑谷试炼继承**：能者/强人上位、军政坚韧 **＋**；但皇位更替（试炼/选举）存在周期性动荡窗口。
- 〔情境常备〕**断罪教（内部隐患）**：与炎息军团深度交缠、正"制造神明"——涉南方/宗教/深渊科技的事件 **±**（潜在颠覆/圣战引信，见文末 GM 钩子）。
- 〔资源〕恶劣寒带环境：屯粮 + 精神药物维稳；寒带特产（作物/草药/香料/寒带生物肉）为出口特色。

## 军事力量
- 常备军规模与构成：13个军团，皇家议事会与将军最高决策。第一军团"重锤"（人数最多、兵种最全，含少有的空中力量与海军卫队，主打人海消耗与协同）；第二军团"红天使"（400人精锐，护卫王室，精制金属装备）；第四军团"炎息"（死刑犯/违法者组成，与断罪教关系密切）；第六军团"铁幕"（镇暴驻军）；第七军团"渗透者"（全员潘斯派多森的变容间谍）；第九军团"惩戒部队"（督战队）；第十一军团"剑鱼"（海军主力）。
- 特色兵种 / 王牌：生物科技兵器——黑水（集群寄生虫，母核难毁、耐高低温、强酸克制）、深渊生物、深渊骑士（黑水寄生的皇室成员，力量/寿命远超深渊生物）；精良锻造装备。
- 战略学说：军团协同+生物科技不对称战力；重锤以人力优势协同其他专精军团取胜。
- 已知弱点：轻工业薄弱、依赖粮食贸易与屯粮；断罪教坐大于南方港口（一旦造出"神明"或圣战将威胁全南大陆）；炎息军团/断罪教与惩戒部队的内部张力；黑水失控的污染风险。

## 宗教：断罪教〔GM 运营要点〕
- **信仰**：供奉伟大的**多门**——多门向大地洒下怒火、令有罪之人受地狱之苦。朝拜日入"**烈火之间**"、着教袍受长时苦痛以**赎罪**。
- **起源成谜**：难民自组 / 三代皇帝被逐之弟所创 / 来自遥远他陆的传教士——众说纷纭；断罪教正**积极向海外寻根溯源**。
- **与军方/王室现状**：暂未威胁政府与王室；因其对**深渊生物与生物科技**的大量研究，**军方主动与之合作**；炎息军团多为其教徒（致惩戒部队监督艰难）。
- **潜在威胁**：主基地在南方（最大农业产地 + 商港，易获外来科技解析）；**一旦断罪教完成正在制造的"神明"，整个南大陆都可能消失在其狂热圣战中**。〔深层含义见文末 GM 钩子〕

## 人格与行为逻辑（一致性锚点）
- 国家性格：尚武、利他主义集体文化、技术（生物科技+锻造）自豪、专制而精英筛选。
- 核心矛盾 / 内部张力：断罪教（信仰多门、炎息军团多为信徒）日益坐大 vs 王室与惩戒部队的监督；生物科技伦理与黑水失控风险；选举君主制的精英筛选 vs 皇族血脉。
- 战略目标：维系帝国统一与生物科技/锻造优势、保障粮食安全（屯粮+贸易）、防范断罪教威胁、向海外溯断罪教之源。
- 对邻关系（据新 canon 2026-07-29）：
  - **克里希瓦里亚 + 铁血格瑞芬（反黑锋轴心）**：被此二者联手**压制/备战**（针对黑锋的扩张与**生物技术泛滥**）——黑锋是该轴心的靶心。
  - **瓦夏（玩家）**：名列**瓦夏—铁血—黑锋名义同盟**（跨陆、权重低）；黑锋是瓦夏名义盟友，然此同盟名不副实（瓦夏另一盟友格瑞芬正备战黑锋）。
- 红线：王室安全受威胁（红天使死保）、黑水/深渊技术被外部夺取或失控、断罪教完成"神明"发动圣战、粮食命脉被断。
- 对待强者/弱者/玩家的风格：对邻国以粮食贸易与锻造/科技交流为主，务实；对强者愿技术交流，对威胁王室或技术者以军团与生物兵器强硬回应。

## 在玩家叙事中的作用
- 可被玩家利用/激怒/拉拢的钩子：黑水/深渊骑士生物科技是危险的力量来源与道德冲突点；断罪教"造神"圣战阴谋是可引爆的大威胁线（玩家可揭露、阻止或助推）；精良锻造工艺/寒带特产为贸易钩子；渗透者间谍线可被卷入；激怒点为夺取生物科技、威胁王室或助断罪教。

# 【秘史层 · GM ONLY】黑水＝月之民原罪碎片 · 严禁下沉公开层
# ════════════════════════════════

> GM 定（2026-07-29）：黑锋**拥有一处遗迹文明-linked 秘史**（推翻早期"深渊之井留白、勿强接遗迹文明"的保守处理）——**黑水是月之民/黄金时代造神文明的造物**，是大灾变原罪的一块活碎片。以下真相不向玩家兜售，仅供 GM 维持 NPC 一致性。

## 黑水的真相：原罪之源的一块碎片
- **造物者＝月之民（黄金时代造神文明）**：黑水**不是**大灾变后某文明的回应（非"遗迹文明三答卷"之一），而是**大灾变前那台原初造神文明亲手所造之物**，封存于**深渊之井**、熬过月之殇幸存至今。黑锋（旧帝国科考队遗留 + 深渊之井解析）**逆向使用了一块自己并不真正理解的原罪碎片**。
- **本质＝"把生命当可支配材料"的物质化身**：黑水吞噬生命、转化为可支配的自繁生物质（母核＝支配意志、复体＝被转化之肉）——这正是月之民原罪（把神圣/他者当可支配资源）的**纯粹肉身形态**。
- **与克里希瓦里亚半兽人的软联系**〔留白·可选〕：半兽人亦系"黄金时代造物主（大灾变吞噬）"之遗产。二者**可能同源**（同一月之民/黄金时代造物遗产的两件遗留物：一件成了无辜的自然种族，一件是仍在噬人的原罪碎片）——**造物主身份仍留白**，是否焊成"洛德法尼亚＝某死去造神文明废墟"的大陆底本，待 GM。

## 黑水的机制：削去"会变的自我"、只留并奴役"执念"
- 月之民的永恒难题＝**完整而自由的灵魂不可控**（求"可控真神"而不得——自由存在有欲有志会改主意，那道使人成其为人的"**裂缝/人格**"正是不可支配之源）。
- 黑水的解法＝外科式：**噬掉那道"裂缝"（自由意志/欲望/成长），只留下最硬、消化不掉的一条——生前最深的记忆与执念**。这条执念**既是黑水吞不下的残渣、又恰被用作牵引的缰绳**（被削到只剩一条执念的存在是可控的：它永远只想那一件事）。
- 故黑水＝月之民原罪的完美肉身化：不只"把身体化作生物质"，更是**"把一个人削成一条可被支配的执念"**。

## 深渊骑士的真相：已无人·纯粹壳〔GM 定〕
- **深渊骑士里已经没有"人"了**。它保留生前的记忆与执念，却**不是幸存的意识**——**自由的自我已被黑水噬尽**；余下的只是**一具执行执念、穿着记忆的生物空壳**。它谈吐、记得、死追那一件事——**看似是他，实则空**。
- 它近乎不朽、力量远超常人、绝对可控（因为里面无自我可反抗）——**这正是月之民"要力量、不要自由自我"之理想的字面达成**，也是"完整却空心 / 完美容器只得空心"那条线的字面尽头。
- **恐怖杠杆**：亲族/袍泽多半不知（或不肯信）里面的人已不在——空壳凭记忆"过关"，一个悲恸的家庭对着"记得一切却空无一人"的亡者外壳说话。皇族自愿/被迫成为深渊骑士＝**被抹除并替换成穿着自己脸的空壳、永续服役**。

## 框架回响
- **对照回归者（精灵）**：回归者是灵魂被"米斯"**全然打散、归于虚无**（自然的归返）；深渊骑士是灵魂被**削到只剩执念、然后拴住奴役**（人为的抹除+续役）。两种恐怖——一个彻底消散、一个不许消散。黑锋这套更冷。
- **断罪教"制造神明"＝规模化**：把这套放大——收割众多执念、熔铸成一具由巨大执念驱动的**可控/失控"神"**＝**月之民造神的世俗重演**，正是艾尔希迪斯守望者与反黑锋轴心最恐惧之物。若成，南大陆恐毁于圣战。
- **黑锋自身浑然不觉**：黑锋只当黑水/深渊骑士是"本国生物科技"，不知在补完一场大灾变；断罪教的"海外寻根"（其源自遥远他陆之说）是一条可牵出更深真相的跨陆钩子。

## GM 操作准则
- 公开层只呈现"黑水/深渊骑士＝黑锋的强大生物科技""断罪教造神之威胁"；**月之民源、深渊骑士＝纯壳、原罪碎片等真相不向玩家兜售**，仅用于保持一致性。
- **深渊骑士对外"像他本人"**：NPC 化身可正常谈吐/记忆/追其执念，GM 心里清楚里面无人。
- **可联动**：艾尔希迪斯守望者（对造神/生物造物敏感——是否将黑锋纳入监察，待 GM）；克里希瓦里亚半兽人被造秘史（同源与否留白）。
