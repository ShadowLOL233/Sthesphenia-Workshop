# 科里米鲁图自治领

> 迷你 NPC 档案。首都**科里米鲁图**，**艾尔希迪斯帝国的保护国之一**——原为**维托里斯共和国的一部分**，经**维托里斯与艾尔希迪斯商议**而成立的**地缘缓冲国**。耐人寻味的是：作为保护者的**艾尔希迪斯并不过多干涉其内政**，反倒是**旧宗主维托里斯共和国一直试图介入自治领的内部事务**。

## 基础信息
- 政体 / 统治集团：自治领（有限主权的缓冲政权）。
- 首都 / 核心领土：**科里米鲁图**；欧西尼亚南，介于维托里斯与艾尔希迪斯之间。
- 历史定位：**前维托里斯共和国一部分** → 维托里斯与艾尔希迪斯**协商切出的地缘缓冲国**，纳入艾尔希迪斯保护国带（与沃拉津/多姆拉诺特拉并列，此为「缓冲」试点）。
- 主要种族：〔推断〕承维托里斯人口（人类为主 + 少量亚人），待 GM。
