# 奥鲁阿尔苏瓦共和国

> 迷你 NPC 档案。**人类为主，羽翼人＋半兽人＋鱼人为辅**的共和议会制国家，首都**费弗贝吉**。作为欧西尼亚北部少数拥有**常年不结冰海港**的国家之一，其海贸虽不及邻居博科达伊克洛索亚联邦，却凭**对浮晶技术的重投入**与**首批建立浮晶商贸舰队**，在经济体量上足以与博科达竞争。历经多轮内政与经济改革，共和国已**渐离人类至上主义、转向泛种族共和主义**——其改革成果，很可能成为此后数十年**以人类社会为主导之成功改革**的重要参照。

## 基础信息
- 政体 / 统治集团：共和议会制（多轮改革后的泛种族共和政府）。
- 首都 / 核心领土：**费弗贝吉**；欧西尼亚中北（r0_c2 中部），扼**常年不结冰海港**，博科达伊克洛索亚联邦之东邻。
- 历史定位：以浮晶技术投资 + 首批浮晶商贸舰队立身；经多次改革由**人类至上主义**转向**泛种族共和主义**，被视为人类主导成功改革的样板。
- 主要种族：**人类为主**＋**羽翼人 / 半兽人 / 鱼人为辅**（泛种族共和框架下渐趋平权）。
