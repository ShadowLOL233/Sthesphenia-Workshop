# 艾尔希迪斯帝国

> **一句话定位**：以龙族与龙裔为中枢、以《龙律》为法理根基、经历过一次根本性自我修正（第一纪元→第二纪元）的古老"赎罪帝国"。它最深的特征不是强大，而是对"自身为何仍有资格存在"怀有近乎苛刻的自觉。
>
> **建档层级说明**：本档案**正文=公开层**（玩家可见/可推理层）；文末【秘史层·GM ONLY】为 GM 一致性锚点，**严禁下沉公开层、玩家不可见**。设计方法论警告见文末（避免把"开放张力"答死、关闭协作入口）。

## 基础信息
- 政体 / 统治集团：**围绕《龙律》文本建立的"宗教法院＋学术院＋议会"复合宪制**，龙族/龙裔为中枢但**并非纯血统专属**。皇帝是**体系最高执行端**，非体系主人；真正凌驾一切之上的是 **七圣议会**（七位大灾变亲历者、《龙律》最初策划与构建者，至今监督皇帝与帝国）。
- 首都 / 核心领土：**帝都泰里昂德尔姆**（起源于古龙语、经上万年通用语使用"磨圆"的混血名——"根是龙族的，城属于所有人"，合第二纪元自我定位）。核心领土=欧西尼亚中南偏西一超大版图，跨多行省。
- 人口 / 经济基础：超大人口的多种族帝国（龙族/龙裔+人类/精灵/矮人及地方共同体）；**魔导与工业并行**——魔导由龙族/龙裔主导、握战略性高危领域，工业为被吸纳驯化后运转于龙律秩序内的产业。以吸纳（而非征服）扩张：收税、修路、审案、调粮、整港、平匪的庞大国家机器。
- 立国神话 / 历史定位：大灾变废墟年代由**两位"原初之皇"**（雌雄同体纯血龙族、最接近传说"先祖之龙"形态）共建。官方史观直面"**龙族是大灾变的参与者而非旁观者**"。历第一纪元（极端守望主义）→**决裂之战**→第二纪元（成熟自省期，被视为瑟斯芬尼亚**公历纪元起点**）。
- 主要种族：龙族/龙裔为象征与法理中枢；非龙族（人类/精灵/矮人等）已深嵌行政、学术、军工、城市经济，在财政/交通/工造/司法记录/外务中作用日益不可替代。**上升凭境界与担当、不凭血统**。

- **技术等级（双轨，GM 草拟）**：
  - **① 常规技术体系 = T3（成熟；魔导领域局部逼近 T4）** — 与其他国家**对应可比**的路线：工业 / 魔导 / 炼金。魔导深度居 1890 全球顶端（可远洋穿越魔力风暴），但奉"先消化再纳入"、工业革命浪潮采纳刻意慢一拍，故非全面高阶。（1890 全员挤在 T1–T3 窄带，此轨面板≈可当绝对实力，唯魔导远洋是稀缺乘数。）
  - **② 守望者遗迹科技 = 独立轴（非常规、不可与他国 T 级并比）** — **独立于工业·魔导·炼金三条常规路线之外**，源自黄金时代/大灾变遗物，是"守望者文明"身份的技术根基（**原初之塔即其巅峰造物**）。代际远超 1890 常规窄带（黄金时代余泽），但**非可量产的日常国力**：帝国以**封存 / 研究 / 分级管控 / 择要动用**为主，绝大部分不可复制、不可外流，动用受《龙律》与七圣议会严格约束。此轨是艾尔希迪斯区别于一切"仅靠工业/魔导堆料"强权的根本。〔其真实性质与武器化细节属秘史，见文末〕

## 修正提示（裁定用，不改面板基数）
> 非面板修正按类型打标签，裁定"定难度"时加减档。单国项写这里；成对项（距离/共界/纽带）进 `relations/`、`geography`。
- 〔技术〕**魔导巅峰 + 穿越魔力风暴的防护航技**：远洋/魔导/接触隔绝文明（如千月暮雪）相关行动 **＋**（少数掌此技者之一）。
- 〔技术·遗迹〕**守望者遗迹科技（独立轴、非常规国力）**：在**守望/压制灾变级危险**这类特定场景可动用远超代际的遗迹造物，效果**碾压级**；但受《龙律》+七圣议会严格约束、极少动用、不可外流，**日常国力对抗不计入**——它是叙事级战略底牌，非可反复调用的常规军力。
- 〔情境常备〕**"先消化再纳入"膜层同化**：采纳外来/新兴工业技术 **−**（比旁人慢一拍；世界加速时同化速度可能赶不上——深层风险线）。
- 〔情境常备〕**见证者外交（不再自认拥有替他人决定之权）**：主动军事干预倾向 **−**（先派学者/使节/誓约见证人对话劝告）；但一旦判定危及**广域秩序**，转为为自身安全/边防/知识封存/后果隔离做周密准备。
- 〔情境常备〕**龙族长寿→连续性强但迟钝/傲慢**：应对快速变局/新范式 **−**。
- 〔情境常备〕**非龙族上升 / "半融者"张力**：涉血统—普遍主义—律法解释权兑现的内政议题 **±**（同化成功之产物，反成自我主张之源）。
- 〔地缘〕**古老双雄并立**：与法涅罗斯（欧西尼亚东部大国）长期"既合作又紧张"（皆古老、皆有强烈自我解释欲）。

## 军事力量
- 常备军规模与构成：龙族/龙裔为高阶指挥与战略核心，魔导为高危战略层，工业化常规部队为主体骨架；**将领须是誓约承担者，非纯效率操作者**。
- 特色兵种：魔导构造/法阵与龙族战力为战略性高危层；远洋魔法防护舰队（可穿越魔力风暴）为稀缺战略资产。
- 战略学说：**"守护而不僭越"**。军队=被许可运行的暴力结构，荣耀不来自纯粹胜利，而来自用暴力的方式是否仍在秩序之内。**克制不靠"事后可叫停/挽回"的机关、也不靠对自己人层层提防，而靠"在龙律中被养成、立过誓、为所行负责的人"**。
- 已知弱点：非扩张导向、决策审慎迟缓；多层制衡致反应慢；对加速变局易低估；广域动员前倾向先外交。

## 人格与行为逻辑（一致性锚点）
- 国家性格：**守成·自省型古老帝国**（"赎罪帝国"由第一纪元的永恒自我惩罚，转为第二纪元"带着创伤/记忆/责任继续活下去"）；厚重、冷静、缓慢、极仪式化——**"秩序必须可以被看见"**。
- 核心矛盾 / 内部张力：① **先辈之庭**"过去从未真正离去" vs 当代判断责任（"可咨询先辈，不可推卸判断"）；② 非龙族上升 / "半融者" vs 龙族主导的普遍主义能否兑现；③ "先消化再纳入" vs 加速的世界（膜层同化恐赶不上）；④ 第二纪元共识被时间稀释（当代龙族无亲历经验，有人嫌走太远、有人嫌不够彻底）；⑤ 是否为第一纪元强制干预/遗物销毁的历史后果承担政治后果、如何补偿。
- 战略目标（长期想要什么）：维系龙律秩序的**连续性与责任承担**；以吸纳同化（非征服）稳固/延展秩序；对危险力量以见证—对话—劝告方式介入，仅在危及广域秩序时周密备防。
- 红线（触发激烈反应）：有力量重演大灾变式"抛硬币"文明豪赌 / 失控高危古代魔法 / 危险遗物滥用；有人试图把帝国拖回第一纪元极端逻辑；**广域秩序**受实质威胁。
- 行为风格：对**强者**=以历史重量与近乎耐心的姿态对话、合作与防备并存；对**弱者**=不歧视但视为"被保护者"，倾向吸纳同化而非消灭奴役；对**玩家**=先派学者/使节/誓约见证人严肃面对面对话、试图以"我们曾走过这条路"劝服，尊重对方选择、同时为后果隔离做周密准备（耐心≠软弱）。

## 在玩家叙事中的作用
- 当前服务的玩家线：**千月暮雪**（玩家）的稀有外部纽带之一——掌穿越魔力风暴的魔法防护航技，是暮雪与外界贸易/技术/情报咽喉（另一纽带=法涅罗斯）。同时是欧西尼亚中南西的"历史已知、今日行为仍需破译"的古老秩序大国。
- 可被玩家利用 / 激怒 / 拉拢的钩子：
  - **"境外试水"机制**：帝国把新技术/新事物放到境外或**松散附属国**先试——玩家国可成为其试水对象、中介或博弈筹码。
  - **见证者劝告**：当玩家文明走向被帝国判定为危险的抉择，会先迎来帝国使节团的严肃劝告（可被拉拢/激怒/利用为外交戏剧）。
  - **法涅罗斯—艾尔希迪斯的合作—紧张**：两古老大国的微妙关系可被第三方玩家撬动。
  - **内部张力**：非龙族上升 / "半融者"自我主张，可被外力（含玩家）撬动或声援。

## 派系与制度速查
- **决裂之战两方（纪元分界轴，公元前）**：守律派（第一纪元原则坚守者）↔ 忏悔派（决死突击、终止/转化中央装置者）。二者**在第二纪元被同时纪念**（成熟之证）。
- **第二纪元/当代政治轴**：承理派 ↔ 重律派（"森林 vs 身体"张力）。—— **勿与决裂之战两派混淆**。
- **中央装置**：公开层称 **原初之塔**（旧称"承载之塔/宁静之堂"；边疆异称"守望枢核/献祭之塔"）——第一纪元终极防御机关 → 第二纪元**龙族死后意识的共同承载空间 / 跨代对话空间（先辈之庭）**；两位原初之皇意识仍存于塔内。进入资格严格受限，久留会致人格投射失衡。皇帝加冕前必经"**首面**"仪式（非宪法强制，却是统治资格最深门槛）。
- **五机构**：七圣议会（最高·监管皇帝）｜龙族议会（立法/政令）｜帝国议会（全族象征性参与）｜解律司（释现象·面向过去与现在）｜启律司（释预言幻象·面向未来）。修律者=二司中经审查得释《龙律》者，龙裔为多、不排斥非龙族。
- **《龙律》三律**：**形**（可命名界定的结构）｜**流**（结构在时间因果中的持续变动）｜**誓**（智慧生命以承诺把自己嵌入可被信任的共同世界）。第二纪元核心更正：**塑造造物者而非排查器物；防的是"孕育回归者之思"，不是材料技术本身**。

## 载荷性秘史（NPC 一致性锚点）
- **本体论倒置**：野兽=原初完整形态；**人格是从完整内部裂开的"珍贵缺陷"**。先祖之龙=第一头获得人格的神兽（"第一道裂缝"），故为残缺体、非最强非最纯——两位原初之皇的雌雄同体返祖即对应此"人格第一道裂缝"。
- **守望者 vs 回归者（运动方向，非血统）**：守望=认下"没有安全的那一口"、直面不可逆而担责；回归=逃避/求圆满而卸去人格与罪疚（混沌派求成龙神=体内的回归者之思）。**若把回归者彻底清除=龙族自己变成回归者=龙律因成功而死（文明级"亢龙有悔"）**。
- **半融者=文明的活缺陷**：现实深嵌帝国、精神未皈依龙律的非龙族，是**永久而稳定**的特征。文明尺度阴阳相扣：**过度同化→完整→死**。最深危险是"因圆满而死"。
- **制度化的自我不信任=最大失败（调头）**：帝国最危险的漂移不是外敌来攻，而是"守望者开始把自己活成一台自我监管的机器"——把被养成、本该被信任的人降格为"待收容的危险",是月之民原罪（把神圣当资源）的内向翻版。→ 故公开层刻意抹去一切"给武器装可叫停机关/对自己人层层提防"的设计语言。
- **神格熔炉之漂移**：中央装置在第一纪元经漫长岁月结构偏移、思想固化，固化到连忏悔派都怕它已成新的灾源——这是"守望之意志须代代续立、否则朝回归漂移"的铁证，也是决裂之战的真正动机。
- **两面镜子（跨种族道德倒置）**：两位原初之皇（在塔中、自愿承担、至今仍存）↔ 至高魔导王（精灵始祖、已飞升原象/回归者之顶点）。守望者"罪在所为、靠内部异见自赎"（献祭成功、先皇仍在）；回归者"罪在被造成何物、终归流失"。**有罪者得到了比无辜者更好的结局，是刻意的道德倒置。**
- **世界道德锁眼（一切推演基线）**：现存种族都是黄金时代造物中无法整体存活者的幸存余烬，活下来靠疯狂年代里分散个体互不知情地"选择拯救他人"。**世界是黑暗的——但它立在慈悲之上。** 龙族是例外（自由存在、靠内部异见自救）。

## ★设计方法论警告（草案第八节·本条对话真正重点）★
- 上述秘史挖到了**小说级设定**（具体真相、已演化完成的哲学立场）；公开层刻意保持**设定集级**（只给气质与开放张力）。
- **风险**：每回答一个"旧艾尔希迪斯保留为开放的核心矛盾"（遗物处理、开国真相、是否干预小国），就**关闭一个协作入口**。对单人叙事完美，对共享世界观协作可能是负担。
- **GM 操作准则**：神秘感**转移到当代**（先辈之庭每日对话、当代决策层动态、哲学如何落到具体情境）——如现实大国"历史已知、今日行为仍需破译"。**引用秘史时只用于保持 NPC 行为一致性，不向玩家兜售"真相"。**
