# 吉亚尔马吉亚王国

> 迷你 NPC 档案。**由耀狮帝国与费尔伦德尔帝国共同扶立的缓冲国**，首都**艾蔡尼棱**。**内政混乱、受制于两大帝国**——夹在两强之间的傀儡缓冲。

## 基础信息
- 政体 / 统治集团：王国（名义世袭君主，实为两大帝国夹制下的缓冲政权）。
- 首都 / 核心领土：**艾蔡尼棱**；欧西尼亚西南，**耀狮帝国与费尔伦德尔帝国之间**。
- 历史定位：**耀狮 + 费尔伦德尔共建的缓冲国**——为隔开两大帝国而立，先天受制于两者。
- 主要种族：〔待 GM〕——两人类工业帝国夹缝，暂按人类本位起草。
