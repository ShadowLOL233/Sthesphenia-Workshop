# 多姆拉诺特拉共和国

> 迷你 NPC 档案。首都**安娜威林**，**艾尔希迪斯帝国的保护国之一**。与沃拉津共和国一样是**开放包容的社会**；得龙族庇护，**人口与经济俱充沛**，遂成**龙族推行「人类工业革命」的试点地区**——即便地处**严酷的自然环境**，也拥有出人意料的国力。

## 基础信息
- 政体 / 统治集团：共和国（开放包容的多族社会）。
- 首都 / 核心领土：**安娜威林**；欧西尼亚南，近艾尔希迪斯帝国，自然环境严酷。
- 历史定位：**艾尔希迪斯保护国 + 龙族「人类工业革命」试点**——龙族借其试验人类主导的工业化范式（与沃拉津的「盟族政策」试点并列为艾尔希迪斯保护国带的两种试点）。
- 主要种族：开放包容社会（多族混居，人类工业化为主线）。
