# 核心设定 (Setting)

> 本文件由 GM 助手依据 `_extracted/` 中的设定源文档（世界观概述第一章、故事背景、技术层级、浮晶设定、种族基础设定等）整理。源 docx 仍保留在 `setting/`，本文件是供推演快速引用的索引摘要。

## 世界基本盘

- **世界名**：瑟斯芬尼亚 (Tharsphennia / Suspendiumnia)，得名于核心资源**浮晶 (Suspendium)**。
- **行星**：巨型大陆世界，地表面积约为地球三倍；**三颗月亮 + 行星环**；重力与磁场接近地球，生态多与地球相似并有独特本地物种。
- **当前纪元**：**开局 = 公历 1890 年**（回合 1）。
  - **公历元年的双重含义**：① **人类首次留下可查证史录之年**——考古发现此期大量文物，足以确认人类文明已发展到能有效记录历史、并透过史书传承历史的程度；② 同年亦是**龙族「大转变」**之年（第一纪元决裂后正式迈入第二纪元）。
  - 〔GM 2026-09-04 裁定〕**二者为巧合**，非任何遗迹文明人工操纵的结果。（当代必有学者不肯相信这一对称是偶然——此为博物学界的常备错误学说之一。）
- **基调**：旧秩序崩解、新秩序未立的动荡上升期——"什么都可能发生，但没人保证飞艇不会下一秒坠落"。王国让位共和国、贵族让位企业、教会让位学会。底层悬着一个共同恐惧：**大灾变会不会再来**。

## 技术时代：双重重建

魔法与工业并行且交织，两者都被各自学者视为可科学研究的对象。**但二者性质相反——这是理解本世界技术格局最要害的一条。**

- **魔法 ＝ 记忆轴（单调递减）**：旧帝国失传的法术/仪式/理论，靠废墟残片一点点重新拼凑（进度极慢，高等精灵学者耗几十年才读懂数页手册）。**当代魔法的衰退并非魔力潮汐所致**（潮汐早在公历前 100–200 年即已平息），而是**远古遗迹知识的持续流失**——自神话帝国时期起，历次世界范围的文明崩溃都造成大量且**不可逆**的技术遗失。故多数文明的技术路线不是「我们能设计出什么」，而是「**我们还记得什么**」；其上限由已经失去的东西封顶。
- **工业 ＝ 设计轴（新生递增）**：蒸汽机、铁路、炼钢炉、浮晶飞艇——全是**最近一个半世纪**从头发展的体系，与旧帝国的原理无关。可推导、可复制、可加速，**不受记忆封顶**。
- **1890 年的特殊性**：这是数千年来**第一次有一条上升线穿过一条下降线**。开局设于此年，根由在此。
- 三条技术轴：**工业、炼金、魔导**（评级见技术层级 T0–T9，下文「技术等级」一节）。

## 浮晶 (Suspendium) — 文明支柱

- 淡蓝/青绿/银白色晶体，存在于空中浮岛、地底岩层及大气微粒中。**类金属导电性**。
- **通电充能 → 以晶体为核心生成反重力立场**，削减立场内物体的有效重量，使大型载具/建筑得以低空航行或半悬浮。电流中断则立场逐步消散。
- 立场强度取决于**晶体质量、几何完整度、内部层纹一致性**；特定几何排列的多晶可形成**稳定共振**，综合升力远超单晶。
- **关键约束**：浮晶**不能**作魔力石用；其**粉尘会干扰/破坏环境魔力流动**并造成长期污染（充能时粉尘被立场抑制，立场消散后扩散）。
- **战略含义**：浮晶文明本质是**加工文明**——国力强弱不只看矿脉，更看晶体学、切割、精密制造与维护能力。飞艇升空发生于约**23 年前**，自此天空成为可经营、争夺、统治的新边疆。

## 超自然 / 魔法规则

- 魔力源自世界本身；所有生物体内都含魔力，魔力可跨种族/物种形成"枢纽"。
- **种族魔力适性差异巨大**：高等精灵适性极高（魔法渗透社会方方面面），劣种半兽人几乎无感知。非类人生物的智慧与其接入魔力枢纽的程度相关——许多魔兽/野兽被驯为牲畜、坐骑、伙伴。
- 大灾变曾导致**魔力枯竭 + 魔力潮汐**（施法者受不可逆伤害）；潮汐自大灾变起**一直持续到公历前 100–200 年**方告平息，历时约 2300–2900 年，几与大灾变混乱首尾相接。**当代魔法的衰退与潮汐无关**（潮汐平息距今已近两千年），成因见上「技术时代」节。

## 种族（概览）

精灵、四足人、矮人、鱼人、羽翼人、半兽人、蜥蜴人、巨人、血族、龙族及亚种等。详见 `setting/瑟斯芬尼亚种族基础设定.docx`（约 3.2 万字，未在本摘要展开）。

### 种族关系的世界公理（GM 2026-08-30 立·多国建档共用底盘）
- **默认走向战争**：多种族多文化并存，种族间的隔阂与不理解**几乎必然存在**；各族出于**种族存续**对资源/地盘的诉求与标准彼此不同，而**解决这种差异最"有效"的手段往往是战争**——血腥但有效。对现世多数种族而言，**这是常态**。
- **多种族共存＝稀有且脆弱的特例**：欧西尼亚虽有数个允许多族并存的国家，但它们都"过于独特"、且**许多特例相当脆弱**——
  - **遗迹文明型**：[艾尔希迪斯](../nations/艾尔希迪斯帝国.md)（龙律）、[法涅罗斯](../nations/法涅罗斯帝国.md)；
  - **地区政治/文化/历史催生的熔合倾向型**：[百国公约](../nations/百国公约.md)（尊重差异的共处联邦）、[费尔伦德尔帝国](../nations/费尔伦德尔帝国.md)（半强制熔合的单一"人族"）；
  - 以及一批只在"多种族文化"定义边缘游走的例子。
- **"亚人"定义（钉死·多档共用）**：**亚人＝除精灵、矮人外的类人种族**（半兽人/蜥蜴人/四足人/羽翼人/鱼人/巨人等）。精灵、矮人**不属**亚人。
- **人类的悖论：体弱而善组织**：人类在冷兵器时代几乎一直是弱势一方（体质/魔力多偏弱），唯一的结构性长处是**最擅长组建大规模文明 + 凝聚力**。故**人类帝国是罕见特例、且常压不住亚人叛乱**；地图默认底色是**碎片化的亚人种族国/氏族**。**技术（工业，或自建的魔法体系）＝打破此格局、让人类真正立国的"均衡器"**——弱而众者靠量产/体系压过强而寡者。
- **人类至上主义（反复出现的应对范式）**：以**人类为中心**，**以"恩典"纳精灵（高等种）、矮人（兄弟种）为"文明共同体"**，对**亚人或剿或奴**、并以"文明 vs 下等野蛮"自我正当化。典型＝[耀狮帝国](../nations/耀狮帝国.md)。其反题＝[费尔伦德尔](../nations/费尔伦德尔帝国.md)（熔亚人入"人族"）/[百国公约](../nations/百国公约.md)（尊重差异共处）。
- **应用**：此公理是理解族群冲突、人类至上主义、多族国罕见的底盘；建档/裁定涉及"为何多族国罕见/为何某国走人类至上"时挂靠于此。〔GM 若欲调基调，改此处即全局生效〕

### 历史帝国分期（GM 2026-08-30 立 · 2026-09-04 重构）
> 开局基线＝公历 1890。**两个标签性质不同、不共用年代轴**——一个论来历，一个论年代。

- **神话帝国 ＝ 性质标签**：指与**黄金时代幸存者**有过直接接触、因而留下文献与传说的文明。大灾变中有极少数以魔法或非魔法途径达到黄金时代高度的特殊个体存活下来，其与人类及新时代人形种族的接触留下了历史文献——这正是「神话」之名的来源之一。**特征＝有名。**
  - **遗迹文明亦归此类**，故当代学界的说法是：**世上仍活着两个神话帝国**——[艾尔希迪斯](../nations/艾尔希迪斯帝国.md)与[法涅罗斯](../nations/法涅罗斯帝国.md)。
- **旧帝国 ＝ 年代标签**：指一切经考古确认存在于**公历 1200 年前**的帝国。**特征＝无名。**
  - **失名机制**〔GM 2026-09-04〕：其名并非被所有人遗忘，而是记得的人**要么已不在人世，要么无意公诸于世**。遗迹文明即属后者——它们收集信息的初衷始终是「这些信息如何服务于自身目的」，而只在历史中匆匆走来又匆匆离去的旧帝国，不足以引起其注意（**沉默出于冷漠，不出于隐瞒**；犹如无人在意路边蚂蚁的死活）。
  - **少数仍留有名者**：如 **瑟伦贝浮尼亚帝国**（精灵主导的多种族古帝国 · 公历 1200 前 · r2_c0 西南霸主，其衣钵后落入人类之手）。
- 〔公历 1200 后至开局＝当代史层。〕

## 技术等级 T0–T9（评级标尺）

三轴（工业 / 炼金 / 魔导）共用的宏观阶段。开局国家通常落在 **T1–T3**。

| 级 | 名称 | 一句话 |
|---|---|---|
| T0 | 知识复兴与秩序重建 | 活下来优先；知识碎片化、依赖个人天赋，遗产物件只会用不懂原理 |
| T1 | 复兴工艺 | 蒸汽与可控热能出现；火枪连队、蒸汽炮；炼金/魔法仍是附属 |
| T2 | 动力工业起始 | 可控动力稳定、机械可重复；炼金标准化量产；中等常备军 |
| T3 | 体系工业成型 | **三轴首次同时工程化**；法阵标准化、浮晶工程化突破；空域与战争形态被重塑 |
| T4 | 高复杂工程 | 跨区域基建常态；炼金介入生命/灵魂/物质重构，构造体入伍 |
| T5 | 稳定体系部署 | 技术固化为可靠但脆弱；创新被迫转入隔离/军工/保密机构 |
| T6 | 战略工程 | 工程直接重塑地理/空域；巨型构造体常规化；失败 = 体系级崩溃 |
| T7 | 三轴全面融合 | 工业/炼金/魔导不可区分；"不可局部失败"，多毁于自身协调极限 |
| T8 | 遗产技术再现 | 稳定使用部分灾变前遗产；高度发达却极不自由，被自身无法再现的成果束缚 |
| T9 | 大灾变源头文明 | 仅描述导致大灾变的原初/守护者级存在；**不对任何玩家或国家开放** |

> 技术等级不等于强弱，而是**结构性代价**：越高级，制度越复杂、社会张力越大、改革越易反噬（详见 `rules/resolution-rules.md`）。

## 大灾变与其后的崩溃序列（背景真相未知）

**大灾变**发生于**公历前 2500–3000 年**（距开局约 4390–4890 年），成因众说纷纭（魔法战争 / 神罚 / 远古存在苏醒 / 旧文明科技灾难），无一可证实或证伪。三大确证影响：**魔力枯竭与潮汐**、**生态剧变与"死地"**、**知识与文化断层**。其后的混乱一直延续到**公历前 800–900 年**方告结束（历时约 1600–2200 年）。

**其后另有两次世界范围的文明崩溃，合计三次：**

| 次序 | 年代 | 标志 |
|---|---|---|
| 一 | 公历前 2500–3000 | 大灾变本身 |
| 二 | 约公历 300 | 神话帝国期终结 |
| 三 | 约公历 1000–1200 | 旧帝国期终结（[耀狮帝国](../nations/耀狮帝国.md)所记「亚人军阀混乱」即其西南面孔） |

每一次崩溃都造成**大量且不可逆**的技术流失，是当代各国仅掌握基本技术的根本原因（见上「技术时代」节的记忆轴）。

> **公开层的学说地位**〔GM 2026-09-04〕：三次崩溃的**存在与年代**属考古可确认的事实；而「三者彼此关联、皆为**争夺遗迹遗产的继承战争**、且无一有赢家」——这一解释在当代**仅为未获定论的学说或传说**，史学界与博物学界各执一词，玩家可自由采信或驳斥。〔其真伪属 GM 秘史层，不在此处判定。〕

> **信息分级**：关于月亮、行星环、大灾变、远古文明的更深真相属于**世界层（GM 专属）**，不通过任何文档预先告知玩家，只能在扮演中逐步浮现。

## 玩家与 NPC 的关系基调

- 玩家是世界观主导者；NPC 用于辅助和推进玩家叙事，需有自洽动机但不抢主线。
- 这不是胜负游戏，而是集体历史书写：国家会兴盛也会衰落，计划会成功也会失败。
