# 面板细化投影（Panel Detail Projection · fluff 层）

> 配套 `resolution-rules.md`（裁定机制）/ `GM裁定指南.md`（面板原理）。本文件定义**把 7 词条面板投影成具体、有味道的数字（兵力/岁入/产能…）的规则**，服务于叙事细节与玩家自定义。
> **一句话定性（勿违背）**：这是 **fluff 层**——它**不参与 `2d6+词条` 裁定**，只把面板结果翻译成玩家看得见的具体数字，为叙事增味。**裁定永远只用面板。**

---

## 一、五条铁律（全维通用）

1. **面板是唯一真值**：一切 fluff 数字都从「相关词条 + 底盘(经/行/社) + 技术等级 T + 体量(人口)」**投影**出来，不独立存在。
2. **严格封顶（信封原则）**：玩家可在投影出的「信封」内自由命名/编组/取舍，但**任何自定义都不能超出面板给的总额**。想突破 → 只能靠推演把面板真正推上去。
3. **只读派生、永不单独记账**：fluff 不逐次消耗记账；**面板一变（重大事件后 GM 更新），就重投影一次**，新数字自然体现增减（战损/繁荣/崩溃）。→ 零漂移（合 `GM裁定指南` 面板恒定有界之旨）。
4. **不反向影响裁定**：fluff 是面板的**下游**；它不能回头改面板、也不进难度。（味道，不是第二套结算引擎。）
5. **可见性三分（公式公开 · 输入分层 · 输出模糊）**：
   - **公式/系数：完全公开**——投影公式与各档表是机制，与 `2d6+词条 vs 难度` 同级该透明；玩家可自算**本国**军力（同「可复算掷骰」精神），亦减 GM 工作量。
   - **输入（面板数值）：分层**——某国面板 7 词条数值属**国家层**：本国自知，**他国需情报行动获取**（据 `resolution-rules.md §八 信息分级`）。
   - **输出（fluff 数字）：对外模糊**——呈现给他国/公开总览走「模糊后对外视图」（数量级/区间/画像，如「约 10–15 师·工业化合成师」）；**唯本国私有页显精确**。
   - **要义**：防「由兵力反推面板」靠的是**隐藏输入 + 模糊输出**，而非藏公式——藏公式无真正安全收益（迟早被反推），只换来无谓不透明。于是形成自然**情报梯度**：公开观察＝模糊估计 → 情报行动＝收窄到精确。

**体量→人口锚**（各维投影共用；GM 可逐国微调）：

| 体量档（总分） | 人口量级 |
|---|---|
| 核心超级大国 49–56 | ~3000–6000 万 |
| 大国/地域强权 42–48 | ~1000–3000 万 |
| 中上 34–41 | ~500–1500 万 |
| 中/小 27–33 | ~200–600 万 |
| 小邦 20–26 | ~50–300 万 |

## 二、军事细化投影（参照实现 · 以「师」为单位 · 定 2026-08-17）

> **兵力单位＝师**：`1 师 ≈ 12,000 人`（工业时代基线；轻/早期 T2 ~10,000、重/T3 合成师 ~15,000，GM 可调）。
> 军力落成 **三个数**：**常备师数 / 战时可动员师数 / 协调梯队**，再挂**每师的质量·装备·类型**。

### 2A. 常备师数（peacetime standing）
```
常备师数 = 人口 × 常备动员率 × 军事修正 ÷ 师规模(≈12,000)
```
**常备动员率** 取 (经+行)/2 档（底盘＝能养多少）：

| (经+行)/2 | 常备动员率 |
|---|---|
| ≤3 | 0.3% |
| 4–5 | 0.5% |
| 6–7 | 0.8% |
| 8+ | 1.1% |

**军事修正**（军事是主杠杆，战损从这里体现）：军9–10 ×1.1 / 军7–8 ×1.0 / 军5–6 ×0.75 / 军3–4 ×0.55 / 军0–2 ×0.35。

### 2B. 战时可动员师数（含预备役）
```
动员上限师数 = 人口 × 战时动员率 ÷ 师规模
```
| (经+行)/2 | 战时动员率 |
|---|---|
| ≤3 | 2% |
| 4–5 | 4% |
| 6–7 | 6% |
| 8+ | 9% |
> **社会整合＝动员闸**：实际能动员到多少而不内爆，由社会整合封顶（低社会强行满动员 → 内乱/负螺旋）。二线动员师**质量降一档**。

### 2C. 每师的质量 / 装备 / 类型
- **质量**（军+社）：精锐师(军8+社6+) / 职业师(军6–7) / 常备师(军4–5) / 征召师(军2–3) / 民兵(军≤1)。
- **装备·类型**（T+技术体系）：T1 火枪连队 → **T2 线列·后膛步枪师+钢炮+早期铁甲/浮晶起步** → **T3 合成师**(连发步枪+机枪+野战炮兵+装甲列车/铁甲舰/浮晶飞艇)。技术体系定普及度；浮晶禀赋另加飞艇/空骑单位。

### 2D. 协调梯队（能把多少师捏成一个拳头）
由 **军事+行政** 定同一战役可有效协同的师数上限——**师多而协调低＝兵力散不成拳**：

| 军事+行政 | 协调梯队 | 一次可协同 |
|---|---|---|
| 14+ | 集团军群级 | 10+ 师 |
| 10–13 | 集团军/军级 | 3–8 师 |
| 7–9 | 军级 | 3–4 师 |
| ≤6 | 师级独立 | 各师半独立、难合拳 |

### 2E. 战前→战后（师本位 · 耀狮例）
- **战前**：耀狮（人口~2000万·经7/行6→0.8%·军8→×1.0）= 2000万×0.8%×1.0÷12,000 ≈ **13 常备师**（合成师·T3·协调 军8+行6=14→集团军群级）；战时可动员 2000万×7%÷12,000 ≈ **~117 师**上限（社会6 限、质量降）。
- 败战 → 面板 **军8→6**：2000万×0.8%×0.75÷12,000 ≈ **10 常备师**。→ **13 师 → 10 师**，战损具现。

### 2F. 正典校验（科罗兹尼亚）
科罗兹尼亚（人口~875万·经6/行7→0.8%·军7→×1.0）≈ 875万×0.8%÷12,000 ≈ **6 常备师 ≈ 7万** —— 正对其正典「**七万线列国防军**」。**人口＝逐国微调旋钮**：用它把模型对齐既有正典（面板定结构、人口定标定）。

### 2G. 玩家自定义信封
玩家拿到「常备师数 + 可动员师数 + 质量档 + 装备/类型 + 协调梯队」，信封内可自由：命名番号、编组、指定王牌师/特色兵种、**以量换质**（少编精锐 vs 多编普通）——但**总师数与协调梯队不可逾越**。

## 三、其余六词条的投影框架（同模板 · 用时细化）

> 六维各有其「头号 fluff 数」，由「该词条 + 相关底盘 + T + 体量」投影，玩家在信封内自定义，面板一变即重投。以下为框架，**细化系数待各维正式启用时按军事同法定表**。

| 词条 | 头号 fluff 数 | 信封驱动 | 玩家可自定义 | 面板降→fluff |
|---|---|---|---|---|
| 经济基础 | 经济量级 / 国库岁入 | 经济×体量×T；行政定征集率 | 产业构成/贸易品/金融机构 | 岁入缩、产业萎 |
| 行政治理 | 有效治理覆盖率 / 官僚编制 | 行政×体量×T | 部院/官制/治理风格 | 覆盖收缩（仅及要地） |
| 社会整合 | 承压上限（可动员% / 内乱阈值） | 社会（+文化底） | 派系/信仰/社会契约 | 阈值降、离心派涨 |
| 科研潜力 | 在研重大项目数 / 突破节奏 | 科研×经济(经费)×T | 研究机构/攻关方向 | 项目减、节奏慢 |
| 对外影响力 | 势力范围/附庸数 / 情报网广度 | 对外×经济×T；地缘二次封顶 | 外交团/情报网/势力圈 | 势力圈缩、附庸离 |
| 技术体系能力 | 年产能 / 可量产技术上限 | 技术体系×经济×T | 工厂/兵工厂/拳头产品 | 产能降、上限跌 |

## 四、投影网互锁（fluff 网 ＝ 面板机器的镜像）

各维 fluff **不是各自为政**，而是同一台机器的不同读数，彼此借用底盘——正好复刻 `GM裁定指南` 的 **底盘(经/行/社) × 流水线(研→技) × 输出端(军/外)**：

- 军事兵力上限 借 **经济(养)+行政(动员)**；
- 科研项目数 借 **经济(经费)**；技术体系产能 借 **经济**；
- 对外势力范围 借 **经济 + 地缘二次封顶**；
- 社会整合的「可动员%」正是**军事战时动员上限**的闸——两维天然咬合。

故底盘弱的国，即便某输出词条高，其 fluff 也被底盘拖住（同 `有效值=min(词条,底盘最弱环+2)` 的精神），**面板的木桶效应在 fluff 层自动重现**。

## 五、维护约定
- fluff **不写死进面板表**；各国档案的军事/经济等段可**附一版当前投影**作对外 fluff（标「据面板投影·面板变则重算」）。
- 面板经重大事件更新后，**重算受影响维度的 fluff**，并在 `timeline/` 记因果。
- 玩家自定义内容（部队番号/产业/派系名）属公开层 fluff，进 `players/` 或速查面板；**不得逾越信封**。
