# GM 裁定指南（面板 · 技术 · 修正的整合方案）

> 配套 `resolution-rules.md`（机制速查）。`resolution-rules.md` 讲**具体判定数字与格式**；本文讲**面板到底是什么、词条如何互动、技术/地缘等修正如何作用**，用于统一 GM 的裁定口径。
> 一句话总纲：**面板 = 时代内的组织效能（原始、可比）；技术等级、稳速器、地缘、情境 = 裁定时的难度与代价，不动面板基数；只有重大事件才永久改面板。**

---

## 一、面板的本质：时代内的"组织效能"，不是绝对实力

国家面板 7 词条（0–10）量的是"**可持续性与组织能力**"——你**在所处时代的框架内，把手头资源经营/组织/动员得多好**，而**不是**你手头东西的绝对威力。

- 一个 T2 国"军事 7" = 在火药时代框架内把军队组织得很出色；一个 T5 国"军事 7" = 同等组织效能，但装备浮晶战舰/构造体。**两者面板同为 7，组织效能相当，绝对战力天差地别**。
- **推论**：同分而技术等级不同 ≠ 同实力。面板可比的是"组织效能"这一层；绝对差距由技术等级承载（见第三节）。
- 例外：7 词条里的 **科研潜力**、**技术体系能力** 与技术等级正相关，故技术差距**部分**已渗入面板，但不是全部。

---

## 二、七词条的互动：一台机器（底盘 × 流水线 × 输出端）

不要把 7 词条当 7 个独立分数相加；它们是一台机器上的不同角色，**相乘、设闸、串成流水线**。

### 底盘三件套（决定"其余能力能发挥多少、撑多久、代价多大"）
- **经济基础 = 燃料/底盘**：给军事、科研、工程供能。**吞吐量的软上限**——弱经济养不起大军或长期研发。
- **行政治理 = 传导倍率**：把潜能变成实际行动的**有效比例**。潜能再高、行政低 = 空转瘫痪（常是"最弱环"的隐藏项）。
- **社会整合 = 承压上限（反噬闸）**：本身不产出，但决定你能把其它词条**往死里推多久才崩**。战争/改革/工业化/技术突破都在抽它；它低，则雄心行动伴随反噬。**技术阻尼的落点也在这里。**

### 创新流水线（idea → 规模）
- **科研潜力 → 技术体系能力**：科研生"新工具/新方法"，技术体系"把想法变成规模化现实"。**任一断点前面白费**。

### 两个输出端
- **军事能力 / 对外影响力** = 强制投射 / 软性投射。都由**经济供能、行政传导、技术体系放大**；`对外影响力`再受**地缘二次封顶**（投射成本/隔离）。

### 互动四原则
1. **木桶效应（规则已内建）**：一次行动的有效力 ≈ 相关链条里**最弱的一环**，不是平均。选词条先问"这件事的链条断在哪"。
2. **底盘是乘数不是加数**：经济 × 行政 × 社会 决定其余词条的"可用比例"。经济 7/行政 3 的国，那 7 只发挥得出一小截。
3. **输出端二次封顶**：军事/对外再高，也被地缘、稳速器、社会整合反复打折。
4. **动态反馈（跨回合）**：正循环 对外→贸易→经济→科研→技术→军事→领土/影响力；负螺旋 激进用兵/改革 抽干社会整合 → 崩则行政/经济一起塌。

### 现成例子
- **冬之桥**：研 9 技 8 却军 4、非国家——技术先锋，但无法自己列装成军（输出端断）。
- **蜂巢-皇权帝国**：研 8 却经 2——能发明、造不起铺不开（流水线在经济处断）。
- **百国公约**：内战抽干社会整合 → 经济/军事/技术一起塌（负螺旋，"输掉过去"）。
- **千月暮雪**：底盘不弱，但地缘隔离把对外投射二次封顶（见第四节修正）。

## 三、技术等级：不进面板基数，裁定时作乘数

技术等级对国力有**两种**作用，分开处理：

- **静态作用（已隐含，勿双算）**：开局规则要求"高技术国分配点数时压缩非核心领域"，故高技术国面板**本就是尖峰型**。这层已体现在数值形状里，**不要再额外加减**。
- **动态作用（不进面板）**：技术越高，**关键行动**（技术突破/超级工程/战略战争/制度改革）越易反噬、代价越大。逐次行动时由 GM 加难度/代价，**且只对关键行动生效**。

### 跨技术等级换算阶梯（裁定跨阶对抗/行动用）
- **每相差 1 阶技术等级 ≈ 裁定难度/质量 一档**优势给高阶方。
- **差 ≥ 3 阶 = 碾压**：低阶方须付出不成比例代价才能抗衡（如莫林多弗铁军 T3 碾压巴塞尼亚的"魔法×火器"旧范式）。
- **开局提醒**：1890 全员挤在 **T1–T3** 窄带，代际差小，**直接比面板≈可当绝对实力**；只有 **T5+ 强权入场**时才需强力乘数。

## 四、修正体系：用"修正提示"账本，不新增数字面板

**为什么不为地缘等另立一块 0–10 面板**：地缘政治大半是**关系型/有方向**（投射成本、共界、缓冲、距离）而非标量，且**定性离散**（隔离/要塞/缺矿），塞进单国一个数字必失真；再立编号面板也违背本系统"弱推演强叙事"的初衷。

**做法**：基础面板保持原始可比；**一切非面板修正进每国的"修正提示"账本**，条目按类型打标签，裁定时作难度/代价。

### 修正类型总表（进面板 vs 不进面板）
| 修正类型 | 例子 | 处理 |
|---|---|---|
| 技术·静态 | 高技术=尖峰分布 | ✅ 已隐含在面板形状，勿双算 |
| 技术·动态 | 改革/突破易反噬 | ❌ 修正提示〔技术〕，裁定加难度/代价 |
| 稳速器（世界级） | 危机密度/社会适配度/技术循环 | ❌ 世界层，非国家属性，裁定时作用 |
| **事件·永久** | 战败/改革/灭国/内战 | ✅ **更新面板**（重大事件后调整） |
| 情境·短暂 | 地形/补给/士气/停火 | ❌ 体现在该次行动的**难度档** |
| **地缘·单国** | 隔离/天然要塞/缺金属矿 | ❌ 修正提示〔地缘〕 |
| **地缘·成对** | 投射距离/共界正面/缓冲国 | ❌ 归 `relations/`、`setting/geography.md` |

### 修正提示块（写入各国档案，紧跟面板之后）
```
## 修正提示（裁定用，不改面板基数）
- 〔地缘〕孤立——魔力风暴，无魔法防护舰船难近：对外投射/外贸/外援 −−；本土防御 ++
- 〔地缘〕缺金属矿：军工量产 −
- 〔技术〕T? → 关键改革/突破易反噬（关键行动 +难度/代价）
- 〔情境常备〕（长期存在的情境项，如内战创伤未愈：军事行动 −1 档）
```
- **单国**修正进本块；**成对**修正（距离/共界/缓冲）进 `relations/` 或 `geography`。

## 五、裁定流程（接 `resolution-rules.md` 的 2d6 判定）

1. **选词条**：从 7 词条选最相关者；跨领域取**链条最弱环**（底盘三件套常是隐藏最弱环）。
2. **定难度**：从基准档（简单6/中等8/困难10/极难12/几乎不可能14）起，按**修正提示 + 稳速器 + 跨阶换算**加减档：
   - 关键行动 + 高技术 → 加难度（技术动态阻尼）。
   - 地缘/情境不利 → 加难度；有利（要塞防御等）→ 减难度。
   - 跨阶对抗 → 每差 1 阶给高阶方一档；差 ≥3 阶按碾压处理。
   - 稳速器（过热期/社会高压等）→ 放大后果或加代价。
3. **投骰**：2d6 + 相关词条 vs 难度（同 `resolution-rules.md`）；裸12大成功/裸2大失败。
4. **结果与善后**：结果叙事化；若为**重大事件**（改革成/败、代际跃迁、制度崩溃、灭国），**才**永久更新面板与修正提示，并在 `timeline/` 记因果。

---

## 六、档案维护约定（配合防膨胀架构）
- **面板 = 原始、可比**；仅**重大事件后**更新（非情境波动）。
- 每国**面板下加"修正提示"块**；成对地缘/关系进 `relations/`、`geography`。
- 面板聚合表由 `scripts/gen_nations_table.py` 生成；修正提示可后续加脚本抽成"修正一览"。
- 稳速器（世界级三档）由 GM 统一管理，不写进任何国家档案。

> 总结口诀：**面板量组织效能、技术定绝对代际、修正提示管地缘与情境、稳速器定时代气候；四者在裁定的"定难度"一步汇合，只有重大事件才回写面板。**
