# 瓦夏联盟

> 玩家国。本档案记录其客观国力与开局既成事实；玩家意图由玩家/GM 掌握。
> 这是 `夏普洛斯` 经"卫国战争 + 安其拉社会主义革命"后的当前形态。**本档案 = 开局正典（2026-07-29 据正式定稿 + 联盟史中卷刷新）**；旧 `瓦夏联盟.docx` 及前身 `夏普洛斯` 为前史。

## 基础信息
- 政体 / 统治集团：**联邦制共和国**（国家主义安其拉社会主义）。本质是**由工人阶级依托公民武装领导的多党派公民政治联合**——公民经定期召开的全国政治联盟（"**安其拉**"）会议把公民意志转为国家意志；根本宗旨＝以强有力统一的国家主义机器强制（弹压）阶级矛盾、发展公民政治、维护国家安全、最终消灭阶级。
- 执政党：**国家主义安其拉社会工党（安工党）**——法定执政党、政治领导核心。三条基本原则：① **阶级立场**（无产阶级立场；短期建广泛真实的公民民主经济、长期消灭阶级剥削）；② **狭义对抗性**（威权精英主义/奴隶主政治/资产阶级共和为根本政敌，消灭强人与社会达尔文政治）；③ **广义国家主义**（"公民"＝服从国家阶级纲领的各阶级统合，国家利益至上与公民利益至上统一，不承认民族/文化矛盾独立作用）。党路线＝去官僚化 + 工团运动 + 集中民主；"党不脱离生产"。
- 政治体制（**真实权力结构**）：
  - **安共会**（国家主义安其拉政治共同联盟总大会）＝法理最高权力、掌立法/修宪，5 年一次总代会，闭会期由**安共中央**行使监督（常设、不直接施政、可废重大违宪政令）。产生自各地方自组的工人政治同盟经安工党联合、逐级向上选举（广泛基层选举 + 基层自治 + 纲领性中央权威）。
  - **安其拉国家联合行政院（联政院）**＝最高执行机关，向安共报告、对**联战委**负责，对地方行政委有强制性。
  - **联合武装战防委员会（联战委）**＝**军事统帅部 + 最高政治决策 + 外交**三合一；**司令≈代议制总统（10 年任期、集中统一领导）**；直接向安共负责、由安共产生并监管。下辖外勤处（外派外交/行政/监察人员）。
  - **国家最高联合法院**＝独立司法、审查监督，独立于政治体系之外。
  - 监察与安全：**安共监察委员会**（权力最大的监察机关，可审查含联战委司令在内各级执行政府）、战防委监察署（非常设反腐）、**联合军保安处（UG）**（国家安全/反间谍/最高军事机密，只对联战委与安共中央负责）、**联合军特别行动署（NSD）**（情报外勤，含前米勒政府秩序部/情报部老骨干后裔）、**武装公民革命战线（ACR）**（军宣 + 民兵训练 + 自下而上宣传体系）、国家联合安全局（各级执法）、联合商务外贸委（因无正式外交部门，代管人口往来/商贸/文化交流）。
- 首都 / 核心领土：原**夏普洛斯城**（斯基普托纳海沿岸，温带森林，富铁矿）+ 扩张后的**瓦兹拉克**地区；工业依赖**米瑟科普**一带煤铁 + 安其拉内战期间南迁的工业。建军地标＝米瑟科普北郊**思克雷恩**。
- 经济基础：**市场经济 + 法团主义 + 国有 + 计划工业化**并行——企业须经"**法团**"与国家计划与工业发展委对接（政府以法律/补助间接导向、战略龙头企业国家控股以遏制垄断，但不干涉企业经营）；三统合＝私有制经济（受工团监督雇工待遇）/ 个体经济（农业集约化个体或集体农户、生产资料国有个体经营）/ 国营经济（军工、关键零件、矿业）。国家粮食委直接干预农业、统购统销、保粮食供大于求。**5 年为一个工业化计划周期**。重视外贸但不理想。
- 主要种族 / 文化：人类为主。因殖民史 + 建国后对外扩张 + 大陆中部十字路口区位，形成**多元文化**——旧帝国式/米格里安式泛拉丁文化 + 东入的格瑞芬欧陆文化 + 南部少量黑锋文化，总体以**拉丁化的夏普洛斯文化**为主；当代主张**摒弃民族差异、树立国家认同**（取代旧的"瓦兹拉克—夏普洛斯民族联盟"观）。

## 政治派系（据定稿 · 六派）
1. **国家主义安其拉社会工党（安工党）**：法定执政党。源自米勒内战期间革命领袖**索迪纳诺斯·安其拉·杜米特库斯**（其父＝索迪纳诺斯·基德）——认同亚米乌斯的平等民主理想却反对其古典共和式"民主"（视之为旧联合走向内战灭亡之因），首创**群众运动**路线。今已是组织严密的工人执政党。
2. **查尔民主社会党（民社党）**：**亚米乌斯的继承者**。学者/中小企业代表/亚米乌斯残部，代表国内私人资本利益（含革命后新兴投机分子）；共和/宪政/民主理念与安工党不矛盾，被视为**联合对抗垄断资本的潜在盟友**。
3. **夏普洛斯联合战线**：米勒旧部中的**激进分子/军内强硬派**（多带小资产阶级或富农色彩、激进民族主义、对旧共和国之敌的强烈仇恨与失乡之痛）。曾被视为非法组织，当今被视为"阶级局限性下的拉拢对象"。**（与"联合军统一阵线"区分）**
4. **世界社会革命工党**：安工党中的**激进分子**，受"人民民主主义共和国联盟"影响而另树新旗——主张**联俄战略**、彻底消灭阶级建完全公有制、世界革命工农联盟。因主张放弃现有外交同盟与国家主义安全战略而遭否定，**但正呈扩大化趋势**。
5. **联合军统一阵线**：起源于瓦夏联合军内部的**爱国统一战线**（退伍及文职军人团体，含现役但现役不得参政）。主张兴军强国、保卫国家安全、保障公民政治权利与福祉，与安工党合作密切。
6. **查尔民主进步党**：由民社党分裂而来，代表职业技术人员/知识分子/产业专员/手工业者 + 大量农业法团代表；主张放宽管制、以经济建设为中心。

## 军事力量
- **人民联合军（PU）**，下设四军种：
  - **国家革命军（NS，陆军）**：原瓦夏联合军，继承亚米乌斯义军传统、作风优良纪律严明；战术＝穿插包围运动战 + 短促突击（要求极高纪律与素养）；改革后大量装甲突击力量为主力；基本作战单位＝师（团为最小独立单位），集团军负责一条战线、多集团军编成集团军群。
  - **中央联合军（CU）**：统帅部直属**旅级特勤**（总兵力约一个集团军），空中突击 + 机械化，战略决战的决定性力量、高速追击扫荡；下辖**国家总军特种部队（NGSF，两个特勤旅）**由联战委直接调动，应对普通安全部队无法应对的最高军事威胁。
  - **联合防空军（UA）**：海空合并的新兴技术兵种（一般以空军为主），改革后统一受统帅部指挥；舰艇偏轻量化、**战列巡洋舰为主力舰**，重火力支援、全域三维作战。
  - **战略打击部队（SS）**：长程大威力直属机动炮兵，战略上轰击要塞/工业城市、消灭有生力量、必要时摧毁决战兵器。
  - 辅助：**建设兵团**（对内国家级工程/职业劳动力动员）、**联勤部队**（保障各军种、必要时参与生产）。
- **军政特务体系**：联合军保安处（UG，国安/反间谍/最高军事机密）、特别行动署（NSD，情报外勤，含前米勒政府秩序部/情报部老骨干后裔）、武装公民革命战线（ACR，军宣+民兵训练+基层动员）。**联合武装力量最高统帅部**在安共选举中常与联战委重合甚至合并（最高统帅头衔归联战委司令），必要时可重组。
- 已知弱点：政权年轻、六派系意识形态分裂（世界工党主张联俄/放弃同盟，与现行国家主义安全战略冲突）；夏普洛斯联合战线极右恐袭余烬；外贸薄弱、工业底子受战争削弱；军事传统偏本土运动战、远征持久攻坚非其所长。

## 历史：意志的胜利·卫国战争（据《联盟史·中卷》；上/下卷未提供）
> 中卷聚焦对**米格里安帝国**的卫国战争（旧历六年末—八年）。这是瓦夏由"民族文化联合"转向"阶级彻底联合"的熔炉，也是安工党与人民联合军的建军史。

- **三政府并立的危局（旧历六年末）**：卫国战争中首都沦陷、政治瘫痪、派系林立，国内三个实权政府——① 名义合法政府＝元帅**卡西乌斯·米勒**残部据守东部海岸工商业重镇**巴兰**；② 激进派**义军**（领导核心＝**霍斯·亚米乌斯**及骨干，郊区活动）；③ **索迪纳诺斯·安其拉**临时组织的**南方联合政府**（新厄尔巴尼亚附近）。旧政府 12 个传统军团半数失能，敌军装备技术占优、规模不明、士气正旺。
- **第二次瓦夏联合（政治转折点）**：围绕亚米乌斯 + 南方联合政府形成。安其拉论断——第一次瓦夏联合是"瓦夏"人民在**民族/文化**意义上的联合，第二次必须是**阶级层面的彻底联合**；瓦夏社会演进须以政治力量联合为直接驱动、分三阶段（前两阶段完成民族解放/持续到国际垄断资本不再威胁国安，第三阶段转向阶级矛盾）。**联合革命阵线**（安工党组织基础）于次年雪天在军队内建立。
- **至暗游击岁月**：米勒军在沃尔瓦战略后不堪再战、义军元气大伤、半数工业与沿海港口被夺、北方乡镇被焚，党一度将政治中心转入深山密林（保党却断群众联系→游击战日渐虚弱），后决意再进军、依赖武装群众，政治指挥中心最终落脚米瑟科普北郊**思克雷恩**（人民联合军建军地标）。安其拉与负伤的亚米乌斯共同确立"**运动战 + 游击主义**"结合的统治路线斗争战略：破坏北方铁路公路、贯彻游击主义护发展群众、工商业离散化改造、党对军队绝对领导并收编义军/米勒派、敌占城市党员网络与情报战。
- **敌焦土与大饥荒**：交通破坏战果显赫，敌转以焦土战略成规模搜剿屠戮，仅一年饿死病死者超建国以来所有自然灾害总和——**仇恨的种子由此深埋全民**。
- **亚米乌斯之死（旧历八年春）**：这位义军领袖身负重伤仍不放枪，终于倒下，遗言"**我这一生，唯独止在重复一件事情，那就是向强权说不。**"年轻的安其拉在孤独中接过旗帜。
- **敌人的真相**：情报显示"米格里安帝国"内政早已极端混乱、可能的领导人正与手足血腥厮杀，其占领区缺乏维持生产的政治基础、市场规则近乎游牧式野蛮，战俘拒答或高呼"为了帝国"、对自身"来源"含糊反感——则加西斯情报部门研判：敌人**不是传统主权国家，更接近非典型"佣兵城邦"**。
- **转折（旧历八年五月·四条报告）**：① 铁道作战与短促突击连战连胜；② 邦尼西城外伏击敌搬空"战利品"的辎重部队；③ 敌自始有组织罢战、向沿海工商业城市龟缩、部分携劫掠物逃往海外；④ 米勒派外勤消息——**米格里安帝国正爆发规模空前、波及大陆的内战，大皇帝下落不明；真正的"侵略者"是米东部高度军事化的自治省"艾格姆斯"叛军，正被（帝国）消灭**。卫国战争由此走向结束。
- **人物余韵**：卡西乌斯·米勒＝**米格里安世家出身**（"你这个米格里安的世家小子"），据守巴兰后于内战中放弃暴力统治理念而自杀；安其拉在胜利的春天忆起卡西乌斯与亚米乌斯"像过去一样"欢笑而去。**这是一个用一代人生命换来的春天。**
